# 剧情索引

大魔王把诗人抓走，想让诗只剩空纸。少年唐小诗从河边的歌谣追到宋词，一章救出一位诗人。

练习库 767 首。历险 41 章 / 162 关。

改剧情请改 `scripts/content/story/`，再跑 `python3 scripts/content/build-bank.py`。
