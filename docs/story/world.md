# 世界观

大魔王把诗人从历史上抓走，想让世上的诗变成空纸。诗住在人身上；人不在，纸会变白。少年唐小诗从最早的歌谣追到宋词，一章救出一位诗人。

对白口语短句，不文言。怪用这一关的诗出题。答对才让路。

## 主线怎么走

1. 先秦：诗从河边唱起。采诗官的歌本空了。
2. 汉魏：有名字更好抓。乐府还在口头，曹操看海，曹植煮豆，陶渊明要回家种地。救出上一朝至少一位，下一朝才开门。
3. 唐：人人会背的那些先丢。从咏鹅、悯农、小儿垂钓走到李白杜甫，收到李商隐的夜雨。
4. 宋：词也是诗。苏轼的月亮、李清照的藕花、陆游的示儿、文天祥的丹心：纸可以白，心里的诗不行。

章内关卡按顺序开。钥匙等于已过的非 Boss 关。集齐才能进最后一关救人。
