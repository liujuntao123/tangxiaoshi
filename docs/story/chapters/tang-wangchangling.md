# 王昌龄章

- 诗人：王昌龄
- 朝代：tang
- 钩子：边关的月还在，写月的人不在
- 时代：盛唐
- 标签：边塞, 冰心
- 钥匙：4

## 开场

- 旁白：秦时明月汉时关。关还立着，月还圆，路上只有风，没有归人。
- 唐小诗：白居易说冰心在玉壶里。边关的月更不能空着。
- 关月精：万里长征人未还。还的是月。人我截在关外。

## 关卡

### 1. 边关

- 诗：《出塞》
- 怪：关月精
- id：`tang-wangchangling-1`

开场：
- 旁白：明月照着老关城。城砖是秦汉的，风是今晚的。路上没有还的人。
- 唐小诗：但使龙城飞将在。将在不在，月都该照着人。
- 关月精：不教胡马度阴山。度不过。你一个小孩，也想来度关？
- 唐小诗：度。月是旧的，人是要还的。
- 关月精：还得过我这关。对上了，关才把月让给你。

过关：
- 关月精：月让了。江上有楼，寒雨连着夜，有人要送客。
- 旁白：一片关月切成钥匙，冷而圆。
- 唐小诗：关我走过了。楼上看看那壶冰。

### 2. 芙蓉楼

- 诗：《芙蓉楼送辛渐》
- 怪：冰心精
- id：`tang-wangchangling-2`

开场：
- 旁白：寒雨把江连成一条。天亮时送客，楚山孤零零地站着。玉壶空着，心不在里面。
- 唐小诗：洛阳亲友如相问。问了也得有人答。
- 冰心精：一片冰心在玉壶。冰是我的。你手热，碰得了吗？
- 唐小诗：碰。心是冰的，话是热的。人要送出去。
- 冰心精：热的进不了壶。对完，壶才肯亮。

过关：
- 冰心精：壶亮了。闺中有人上楼，看见杨柳才知道愁。
- 旁白：一滴壶水凝成钥匙，冰的，不化。
- 唐小诗：冰心我捧着。楼里那份愁，我也去听。

### 3. 翠楼

- 诗：《闺怨》
- 怪：陌头柳
- id：`tang-wangchangling-3`

开场：
- 旁白：春日。少妇梳好妆上了翠楼。陌头杨柳忽然绿了，笑一下子收住。
- 唐小诗：闺中少妇不知愁。不知的时候过去了。写她的人自己被关在外头。
- 陌头柳：悔教夫婿觅封侯。悔是她的。侯你也想觅？小孩。
- 唐小诗：不想侯。想让人回家。柳可以绿，人不能只在路上。
- 陌头柳：绿了就晚了。对上了，楼才把栏杆松开。

过关：
- 陌头柳：栏松了。青海的云把雪山盖住，孤城还望着玉门。
- 旁白：一根柳丝缠在钥匙上，绿得发亮。
- 唐小诗：愁我听见了。沙场那头更不能停。

### 4. 青海

- 诗：《从军行》
- 怪：黄沙精
- id：`tang-wangchangling-4`

开场：
- 旁白：青海长云暗雪山。孤城远远望着玉门关。黄沙把金甲磨出了洞。
- 唐小诗：黄沙百战穿金甲。甲穿了，人还得还。
- 黄沙精：不破楼兰终不还。还？破了才还。你破得了楼兰吗？
- 唐小诗：破诗就行。人不是用来不还的。
- 黄沙精：诗也算一仗。对完，沙才肯让出一条路。

过关：
- 黄沙精：路有了。殿里灯火冷，团扇还在转，有人等到了鸦。
- 旁白：一粒黄沙嵌进钥匙，金甲色。
- 唐小诗：楼兰我记下了。殿里那把扇，我去还。

### 5. 长信殿（Boss）

- 诗：《长信怨》
- 怪：大魔王
- id：`tang-wangchangling-boss`

开场：
- 旁白：奉帚平明金殿开。殿里灯冷。王昌龄被锁在团扇的影子里，玉颜那边没有日。
- 唐小诗：玉颜不及寒鸦色。鸦都能带着日影。人不该比鸦更冷。
- 大魔王：暂将团扇共徘徊。徘不徘徊？昭阳的日——你分得到吗？
- 王昌龄：小诗，壶还是干净的。把这首念完，扇自己会停。
- 唐小诗：扇停。人出殿。月还在关上。

过关：
- 大魔王：……冰心最烦。下一营弓还上弦，夜是黑的，有人写过雁。
- 王昌龄：去找卢纶。月黑的时候，他的弓比月准。
- 唐小诗：营我去。玉壶交给月。
