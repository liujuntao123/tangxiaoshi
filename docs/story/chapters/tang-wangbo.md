# 王勃章

- 诗人：王勃
- 朝代：tang
- 钩子：海内存知己，人却不在城阙
- 时代：初唐
- 标签：送别, 知己
- 钥匙：2

## 开场

- 旁白：长安城阙还在。送别的亭子空了，风烟把五津遮成一条灰线。
- 唐小诗：卢纶说海内存知己。知己被抓走了，话还硬着。
- 三秦精：与君离别意。意在。人在烟后面。

## 关卡

### 1. 城阙

- 诗：《送杜少府之任蜀州》
- 怪：三秦精
- id：`tang-wangbo-1`

开场：
- 旁白：城阙辅三秦。风烟望五津。路远得像没有尽头，送的人却不在亭里。
- 唐小诗：同是宦游人。游可以。把朋友藏起来不算游。
- 三秦精：海内存知己。存？天涯若比邻——邻你现在看不见。
- 唐小诗：看不见也算邻。无为在歧路。我不在路边哭。
- 三秦精：不哭才像。对上了，烟才把五津让开。

过关：
- 三秦精：津让了。山里黄叶在飞，江却像被谁拖住，有人想家。
- 旁白：一缕风烟结成钥匙，远而不散。
- 唐小诗：知己我记下了。黄叶那头，我也去。

### 2. 山中

- 诗：《山中》
- 怪：黄叶精
- id：`tang-wangbo-2`

开场：
- 旁白：长江像被谁拖住，流不动。万里外有人想回家。风一高，山山的叶子全黄了，全在飞。
- 唐小诗：万里念将归。归的路被叶子盖住了。
- 黄叶精：况属高风晚。晚了。山山黄叶飞——飞你也要跟着？
- 唐小诗：不跟叶子。跟人。江可以滞，人不能滞在山里。
- 黄叶精：滞着好玩吗。对完，叶才肯落地。

过关：
- 黄叶精：落地了。风在林壑里来回，没痕迹，却像有情。殿开了。
- 旁白：一片黄叶卷成钥匙，一吹就想走。
- 唐小诗：归我替他念着。风里那座殿，我进。

### 3. 松风殿（Boss）

- 诗：《咏风》
- 怪：大魔王
- id：`tang-wangbo-boss`

开场：
- 旁白：肃肃凉景生。高阁的风把雾卷走。王勃被锁在松下，衣襟猎猎响，还在听有没有松声。
- 唐小诗：去来固无迹。风可以没迹。人要有。
- 大魔王：动息如有情。情？日落山水静——静了你喊得动吗？
- 王勃：为君起松声。小诗，别在歧路站着。把这首喊完，风会带我出来。
- 唐小诗：松声我听见了。人出来。

过关：
- 大魔王：……知己最烦。黄鹤飞走了，楼还在，墙上的字在等人。
- 王勃：去找崔颢。李白都说写不过那首。天涯若比邻，楼也是邻。
- 唐小诗：黄鹤楼。我到。
