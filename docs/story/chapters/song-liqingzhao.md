# 李清照章

- 诗人：李清照
- 朝代：song
- 钩子：争渡，争渡，人却不在藕花里
- 时代：两宋
- 标签：藕花, 想家, 人杰
- 钥匙：3

## 开场

- 旁白：溪亭的酒醒了。船不在旧路。藕花深处有人喊争渡，争的不是她。
- 唐小诗：叶绍翁说荷塘那艘船不能一直迷着。李清照的词又亮又疼。
- 误舟精：误入藕花深处。深是我。人是我收的。

## 关卡

### 1. 溪亭渡

- 诗：《如梦令》
- 怪：误舟精
- id：`song-liqingzhao-1`

开场：
- 旁白：常记溪亭日暮。沉醉不知归路。船挤进荷花，鸥鹭一下子全飞了。
- 唐小诗：兴尽晚回舟。回可以。不能回进你的荷里就不出来。
- 误舟精：争渡，争渡。惊起一滩鸥鹭——惊是我。你争得过这片荷吗？
- 唐小诗：争。路我来找。人从荷叶底下出来。
- 误舟精：出得来吗？对上了，藕花才肯让一条船路。

过关：
- 误舟精：让了。红藕香残，有人独自上了小舟，信还没来。
- 旁白：一滴湖水凝成钥匙，鸥鹭翅膀扫过，还在滴。
- 唐小诗：争渡我赶到了。小舟那头，我去等信。

### 2. 兰舟洲

- 诗：《一剪梅·一翦梅》
- 怪：锦书精
- id：`song-liqingzhao-2`

开场：
- 旁白：红藕香残玉簟秋。席子是凉的。小舟自己漂着，船上没有人。
- 唐小诗：云中谁寄锦书来。雁会飞。书没有。写书的人更没有。
- 锦书精：此情无计可消除。消不掉。才下眉头，却上心头——心我扣着。你解开？
- 唐小诗：解。想可以想。人要从心上头走下来。
- 锦书精：走不走得下来，对完，雁才肯把路让开。

过关：
- 锦书精：让了。东篱的酒还温着。西风一卷，人比花还细。
- 旁白：一页空信折成钥匙，雁没来得及写下字。
- 唐小诗：信我会等。篱边那个人，我先去。

### 3. 东篱夜

- 诗：《醉花阴》
- 怪：瘦花精
- id：`song-liqingzhao-3`

开场：
- 旁白：薄雾浓云愁永昼。夜里帘子被西风卷起来。菊花开着，人比花还细。
- 唐小诗：人比黄花瘦。不是病。是想得厉害。想得厉害，人也要在。
- 瘦花精：莫道不销魂。魂是我抽的。帘卷西风——风我请来的。你比花还瘦吗？
- 唐小诗：我是小孩。我不比。她细，是因为心里装得太多。太多更不能丢。
- 瘦花精：丢不丢，对上了，西风才把帘放下。

过关：
- 瘦花精：放下了。生当人杰。殿里那个人，眼睛比花亮。
- 旁白：一朵黄花别在钥匙上，风一吹，人比它还细。
- 唐小诗：细我懂了。亮的那头，我去。

### 4. 易安殿（Boss）

- 诗：《夏日绝句》
- 怪：大魔王
- id：`song-liqingzhao-boss`

开场：
- 旁白：生当作人杰。死亦为鬼雄。李清照被锁在殿心，眼睛很亮，像不肯过江。
- 唐小诗：至今思项羽。不肯过江东。不是打仗。是人不许自己先软。
- 大魔王：人杰我不当。你一个小孩当不当？词又亮又疼，疼的人更好关。
- 李清照：小孩。别替我软。人杰是自己当的。你把这首走完，锁自己会断。
- 唐小诗：断。把人还给藕花。

过关：
- 大魔王：……硬最烦。稻花香里有人说丰年，说完又想打仗。
- 李清照：去找辛弃疾。藕花我回来了。蛙声那头，不能只有丰年没有人。
- 唐小诗：丰年我去听。人杰记下了。
