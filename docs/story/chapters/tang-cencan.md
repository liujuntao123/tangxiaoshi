# 岑参章

- 诗人：岑参
- 朝代：tang
- 钩子：胡天八月即飞雪
- 时代：盛唐
- 标签：边塞, 送别, 雪
- 钥匙：3

## 开场

- 旁白：八月。营门外白草折了。雪落在树上，像谁一夜间开满了梨花。马上的人呵出白气，写雪的人不在队伍里。
- 唐小诗：韦应物说马上要送人回京。忽如一夜春风来。春风是假的，雪是真的。
- 梨花雪：千树万树梨花开。开的是我。人被我埋在花下面。

## 关卡

### 1. 白雪营

- 诗：《白雪歌送武判官归京》
- 怪：梨花雪
- id：`tang-cencan-1`

开场：
- 旁白：北风卷地白草折。胡天八月即飞雪。帐外雪厚，弓都拉不开，酒杯却还温着。
- 唐小诗：忽如一夜春风来。不是春。是雪装成花，把送人的人都装没了。
- 梨花雪：千树万树梨花开。花是冷的。散入珠帘湿罗幕——幕湿了，人干不了。你还送不送？
- 唐小诗：送。雪可以像花。回京的人要走得成。写雪的人不能埋在雪里。
- 梨花雪：留可以。对上了，这营才把雪门打开。

过关：
- 梨花雪：门开了。东望故园，路很长。马上碰上了进京的使者，袖是湿的。
- 旁白：一朵不是花的雪，冻成钥匙，握着刺骨，看着眼熟。
- 唐小诗：花我认得。平安还没报。

### 2. 入京路

- 诗：《逢入京使》
- 怪：袖泪精
- id：`tang-cencan-2`

开场：
- 旁白：故园东望路漫漫。双袖龙钟泪不干。路上两匹马迎头碰上，纸没有，笔没有，人只剩袖。
- 唐小诗：马上相逢无纸笔。没有纸也要说。凭君传语报平安——平安被你扣在袖里。
- 袖泪精：报什么安。安在东边。你在西边。话我替你收了。收了就不怕写错。
- 唐小诗：不怕写错。就怕家里听不见。话还我，人也还。
- 袖泪精：还可以。对完，袖才肯把话滴出来。

过关：
- 袖泪精：滴了。走马川在雪海边，碎石像斗一样大，风一吹就满地跑。
- 旁白：袖口没有纸，泪渍凝成一把钥匙，还温，一擦就淡。
- 唐小诗：平安我记下了。石我去拦。

### 3. 走马川

- 诗：《走马川行奉送封大夫出师》
- 怪：斗石怪
- id：`tang-cencan-3`

开场：
- 旁白：君不见走马川行雪海边。平沙莽莽黄入天。一川碎石大如斗，风把它们赶得乱走。
- 唐小诗：轮台九月风夜吼。吼就吼。马毛带雪汗气蒸——蒸的是行军，不是抓人。
- 斗石怪：风头如刀面如割。割得动吗？幕中草檄砚水凝——墨都冻了。你的诗冻没冻？
- 唐小诗：没冻。石可以跑。出师的人要走成列，写的人要跟在后面。
- 斗石怪：跟可以。对上了，这川才肯把石按住。

过关：
- 斗石怪：按住了。轮台城头夜里吹角，城北的星像在掉。殿在雪里开了。
- 旁白：斗大的石缝里卡住一把钥匙，边还挂着冰碴。
- 唐小诗：石停了。角声我去听。

### 4. 北庭殿（Boss）

- 诗：《轮台歌奉送封大夫出师》
- 怪：大魔王
- id：`tang-cencan-boss`

开场：
- 旁白：轮台城头夜吹角。轮台城北旄头落。岑参被锁在雪殿里，角声还在他肩上震。
- 唐小诗：戍楼西望烟尘黑。黑的是尘。三军可以大呼。人不许冻在角里。
- 大魔王：四边伐鼓雪海涌。涌。三军大呼阴山动——动一个我看看。剑河风急雪片阔，你阔得过雪吗？
- 岑参：小诗。手冷就搓。雪你已经走过了。把这首喊完，角会停，马会站。
- 唐小诗：山可以动。人要出列。

过关：
- 大魔王：……雪里报平安最烦。姑苏城外有钟，夜半要响到客船，船上没人听。
- 岑参：去找张继。替我再报一句：雪停了，人回来了。
- 唐小诗：平安带到。钟我去听。
