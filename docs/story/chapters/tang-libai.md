# 李白章

- 诗人：李白
- 朝代：tang
- 钩子：月亮还在，楼上没人
- 时代：盛唐
- 标签：月, 山水, 送别
- 钥匙：5

## 开场

- 旁白：月亮村今晚特别亮。小楼的门开着，床前是霜，不是人。
- 唐小诗：王之涣说他比楼高。桌上第一句写着「床前明月光」。
- 唐小诗：月还在。写月的人不能丢。

## 关卡

### 1. 月亮村

- 诗：《静夜思》
- 怪：月霜精
- id：`tang-libai-1`

开场：
- 旁白：地上一层霜。楼上没有灯。月光铺到床前，像有人刚走开。
- 唐小诗：床前明月光。我低头，地上不是霜，是空。
- 月霜精：疑是地上霜。霜是我铺的。举头望明月——望得到，摸不着。
- 唐小诗：低头思故乡。故乡在诗里。人呢？
- 月霜精：人被我藏在光后面。你把这首走完，光才让路。

过关：
- 月霜精：光让了。香炉峰上有瀑布，比月还吵。
- 旁白：一片霜化成钥匙，凉得像井水。
- 唐小诗：月我记下了。人我去追。

### 2. 瀑布关

- 诗：《望庐山瀑布》
- 怪：水帘怪
- id：`tang-libai-2`

开场：
- 旁白：日照香炉生紫烟。瀑布从天上挂下来，像一匹谁也剪不断的白布。
- 唐小诗：遥看瀑布挂前川。李白最爱看这个，人却不在水边。
- 水帘怪：飞流直下三千尺。三千尺我站着。你站得住吗？
- 唐小诗：疑是银河落九天。银河不是用来挡路的。
- 水帘怪：挡不挡，念对了才让你湿着过去。

过关：
- 水帘怪：水还你。桃花潭更热闹，有人踏歌。
- 旁白：水帘里甩出一把钥匙，还在滴。
- 唐小诗：汪伦在那边等过他。我也去。

### 3. 桃花潭

- 诗：《赠汪伦》
- 怪：潭影精
- id：`tang-libai-3`

开场：
- 旁白：潭水深得很。岸上有脚印，踏着踏着人没了，只剩歌声的尾巴。
- 唐小诗：李白乘舟将欲行。船在，人空。
- 潭影精：忽闻岸上踏歌声。歌是我踩的。桃花潭水深千尺——深过友情吗？
- 唐小诗：不及汪伦送我情。情不是拿来比深浅的，是拿来送人的。
- 潭影精：送不送，对上了，潭才把路让开。

过关：
- 潭影精：路让了。黄鹤楼有船要开，帆已经远了。
- 旁白：一瓣桃花贴在钥匙上，沉不下去。
- 唐小诗：友情比潭深。人要比船快。

### 4. 黄鹤楼

- 诗：《黄鹤楼送孟浩然之广陵》
- 怪：黄鹤精
- id：`tang-libai-4`

开场：
- 旁白：故人西辞黄鹤楼。楼是空的。江上一点白帆，像被谁捏走了。
- 唐小诗：烟花三月下扬州。孟浩然走了，李白也该在这儿看。
- 黄鹤精：孤帆远影碧空尽。尽了。唯见长江天际流——流的是水，不是人。
- 唐小诗：人会回来。帆也会。你先把诗还我。
- 黄鹤精：还可以。对完，鹤才肯低头。

过关：
- 黄鹤精：低头了。白帝城的船更快，一日能走千里。
- 旁白：一根鹤羽穿在钥匙孔里。
- 唐小诗：送别我赶到了。快船我还要赶。

### 5. 白帝城

- 诗：《早发白帝城》
- 怪：行舟怪
- id：`tang-libai-5`

开场：
- 旁白：朝辞白帝彩云间。彩云还没散，船已经到了江心。两岸猿声一阵阵。
- 唐小诗：千里江陵一日还。这么快的船，诗人会不会被载走了？
- 行舟怪：两岸猿声啼不住。住不住。轻舟已过万重山——过了你就追不上。
- 唐小诗：我已经在船上。对诗比追船快。
- 行舟怪：快可以。钥匙齐了才进天门。先答。

过关：
- 行舟怪：齐了。两座山像门，殿坐在江心。
- 旁白：船帮上嵌着最后一把钥匙，还带着猿声。
- 唐小诗：天门开着。我进去。

### 6. 天门殿（Boss）

- 诗：《望天门山》
- 怪：大魔王
- id：`tang-libai-boss`

开场：
- 旁白：天门中断楚江开。两座山像门。李白被锁在门中间，酒壶倒了，月还在他眼睛里。
- 唐小诗：碧水东流至此回。流到这儿就不许你再藏人。
- 大魔王：两岸青山相对出。出的是山。孤帆一片日边来——你从日边来？
- 李白：小诗。酒我回头请。先把《望天门山》喊出来，门会让。
- 唐小诗：喊就喊。把门打开。

过关：
- 大魔王：……月最烦。草堂更破，破得有雨，有人还想给天下盖房子。
- 李白：去救杜甫。他比我苦，诗比我真。酒，真的下次。
- 唐小诗：下次算数。草堂我去。
