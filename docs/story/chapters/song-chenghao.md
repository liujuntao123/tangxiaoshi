# 程颢章

- 诗人：程颢
- 朝代：song
- 钩子：云淡风轻，人在近亭
- 时代：北宋
- 标签：云淡, 秋月, 郊游
- 钥匙：3

## 开场

- 旁白：云淡风轻近午天。傍花随柳过前川。路上有花，没有人。
- 唐小诗：朱熹说他心里有一点乐。乐还在风里。人要找回来。
- 花柳精：时人不识余心乐。乐我收了。人我藏了。

## 关卡

### 1. 前川路

- 诗：《春日偶成》
- 怪：花柳精
- id：`song-chenghao-1`

开场：
- 旁白：傍花随柳过前川。花在，柳在。近午的风很轻，走路的人不在。
- 唐小诗：时人不识余心乐。不识没关系。乐不是偷来的。
- 花柳精：将谓偷闲学少年。少年是你。他偷闲，我偷人。公平。
- 唐小诗：不公平。闲可以偷。人要自己走这条路。
- 花柳精：走不走得成，对上了，花柳才把川让开。

过关：
- 花柳精：让了。清溪流过山头，水和天一个颜色，人静过头了。
- 旁白：一片柳叶卷成钥匙，还带着午时的风。
- 唐小诗：乐我识得了。静的那头，我去看月。

### 2. 清溪头

- 诗：《秋月》
- 怪：澄溪精
- id：`song-chenghao-2`

开场：
- 旁白：清溪流过碧山头。空水澄鲜一色秋。白云红叶慢慢走，看的人没有。
- 唐小诗：隔断红尘三十里。隔尘可以。不能把人也隔走。
- 澄溪精：白云红叶两悠悠。悠悠是我。尘我隔了，人我一并隔了。你过得来吗？
- 唐小诗：过得来。月这么清，是给人看的。人要在溪边。
- 澄溪精：在不在，对完，云和叶才肯分开一条路。

过关：
- 澄溪精：分开了。芳原绿野有人乱跑，追着落花，坐到忘了回家。
- 旁白：一枚红叶漂在钥匙上，和白云一样慢。
- 唐小诗：秋我看清了。乱跑那头，我去拉一把。

### 3. 芳原野

- 诗：《郊行即事》
- 怪：苔矶精
- id：`song-chenghao-3`

开场：
- 旁白：芳原绿野恣行时。春入遥山，四面都是绿。有人追着乱红穿柳巷，脚印停在苔矶上。
- 唐小诗：困临流水坐苔矶。坐可以。莫忘归——归的人被你按在石头上了。
- 苔矶精：莫辞盏酒十分劝。劝是我。只恐风花一片飞——飞了就没。人我也飞走了。
- 唐小诗：花可以飞。人要记得回家。清明天气这么好，更要回来。
- 苔矶精：回不回得来，对上了，苔矶才把人松开。

过关：
- 苔矶精：松开了。月陂堤上有人走来走去，北面那台有百尺高。
- 旁白：一块苔石磨成钥匙，坐上去是凉的。
- 唐小诗：郊行走完了。堤上我去陪他转。

### 4. 月陂殿（Boss）

- 诗：《游月陂》
- 怪：大魔王
- id：`song-chenghao-boss`

开场：
- 旁白：月坡堤上四徘徊。北有中天百尺台。程颢被锁在水心云影里，还想再走一圈。
- 唐小诗：世事无端何足计。乱事可以不算。人不能不算。
- 大魔王：水心云影闲相照。闲着好锁。偷闲的人，我让他闲到空。
- 程颢：小诗。乐还在。你把这首走完，堤会让我再走一回。
- 唐小诗：走。云还淡，风还轻。

过关：
- 大魔王：……闲最烦。有个园子门不开，红杏倒先探出墙来。
- 程颢：去找叶绍翁。园子关着，春色关不住。人也不能关。
- 唐小诗：杏我看见了。门我去敲。
