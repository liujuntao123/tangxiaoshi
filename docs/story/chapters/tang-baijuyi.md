# 白居易章

- 诗人：白居易
- 朝代：tang
- 钩子：野草又绿了，写草的人不在
- 时代：中唐
- 标签：乐府, 江南
- 钥匙：4

## 开场

- 旁白：古道边，草又绿了。烧过的黑茬下面，新芽齐齐冒出来。送别的脚印只剩两个。
- 唐小诗：孟浩然说大家都懂他的诗。草会生，人更得在。
- 野草精：野火烧不尽。火我不怕。人我藏在芽后面。

## 关卡

### 1. 草道

- 诗：《赋得古原草送别》
- 怪：野草精
- id：`tang-baijuyi-1`

开场：
- 旁白：离离原上草。烧过一回，春风一吹又是一片。远芳把古道都侵绿了。
- 唐小诗：一岁一枯荣。枯过了，荣了，写它的人不能跟着枯。
- 野草精：春风吹又生。生是我的本事。又送王孙去——送完人，草还在。你呢？
- 唐小诗：我也在。萋萋满别情。情不是拿来烧的。
- 野草精：烧不掉就对了。对上了，原才把路让开。

过关：
- 野草精：路让了。池上有条小艇，浮萍开了一道缝，小孩跑了。
- 旁白：一根新草拧成钥匙，还带着春风。
- 唐小诗：草我抓住了。偷莲的那个，我去池边看。

### 2. 池上

- 诗：《池上》
- 怪：白莲精
- id：`tang-baijuyi-2`

开场：
- 旁白：小艇横在池上。白莲缺了几朵。浮萍被撑开一道缝，藏不住。岸上没有小孩。
- 唐小诗：小娃撑小艇。莲还在，撑船的不在，只剩缝。
- 白莲精：偷采白莲回。偷是他。不解藏踪迹——你藏得住诗吗？
- 唐小诗：藏不住。诗本来就该被人看见。莲还小孩。
- 白莲精：还了也留印。对完，萍才合回去。

过关：
- 白莲精：萍合了。天要下雪，红泥炉子还红着，有人问你喝不喝。
- 旁白：一瓣白莲贴在钥匙上，湿的。
- 唐小诗：莲我还了。酒我闻一闻。

### 3. 火炉屋

- 诗：《问刘十九》
- 怪：绿蚁精
- id：`tang-baijuyi-3`

开场：
- 旁白：晚来天欲雪。红泥小火炉烧得脸热。桌上两只杯，新酒还泛着绿沫。
- 唐小诗：绿蚁新醅酒。请客的人该坐在炉边。
- 绿蚁精：能饮一杯无。无？有？你小孩，也配问这一句？
- 唐小诗：配。天要雪了，人更不能空着杯。
- 绿蚁精：空着多没意思。对上了，炉才把暖借你。

过关：
- 绿蚁精：暖借了。山下花都谢了，寺里桃花才开，春躲在上头。
- 旁白：一粒绿蚁冻在钥匙里，像要化。
- 唐小诗：酒我记下了。春我上山找。

### 4. 大林寺

- 诗：《大林寺桃花》
- 怪：山桃精
- id：`tang-baijuyi-4`

开场：
- 旁白：山下芳菲尽了。山寺里桃花才盛开，像春天绕了路，钻进这道门。
- 唐小诗：长恨春归无觅处。春没走，人走了。
- 山桃精：不知转入此中来。转是春。人间四月——四月你来晚了。
- 唐小诗：不晚。盛开着就来得及。人要跟春一起留下。
- 山桃精：晚开才值钱。对完，寺才把花瓣铺成路。

过关：
- 山桃精：路铺了。江南那座殿开了。江花要红过火。
- 旁白：一瓣山桃做成钥匙，比山下的花晚。
- 唐小诗：春我找到了。江南我去忆。

### 5. 乐天殿（Boss）

- 诗：《忆江南》
- 怪：大魔王
- id：`tang-baijuyi-boss`

开场：
- 旁白：江南好。殿外江花红得像火，水蓝得像染过。白居易站在锁里，还在看那片水。
- 唐小诗：风景旧曾谙。旧的风景在，写它的人要回来看。
- 大魔王：日出江花红胜火。红不红？能不忆江南——你忆得动吗？
- 白居易：能。小诗，这首大家都会。会的，念出来就行。别学我那么啰嗦。
- 唐小诗：江南好。人更好。还来。

过关：
- 大魔王：……人人会的最烦。边关那轮月还挂着，写月的人不在关上。
- 白居易：去找王昌龄。冰心放在玉壶里，比江南的水还干净。
- 唐小诗：关我去。草交给春风。
