# 韦应物章

- 诗人：韦应物
- 朝代：tang
- 钩子：春潮带雨，野渡的船是空的
- 时代：中唐
- 标签：闲适, 友情, 山水
- 钥匙：3

## 开场

- 旁白：西涧的草贴着水。树深处有黄鹂。春潮带着雨赶来，渡口没有人，船自己横着。
- 唐小诗：柳宗元把信交给风了。这儿更静。野渡无人舟自横。船在，人空。
- 横舟精：无人。你来，船会歪。

## 关卡

### 1. 西涧渡

- 诗：《滁州西涧》
- 怪：横舟精
- id：`tang-weiyingwu-1`

开场：
- 旁白：独怜幽草涧边生。上有黄鹂深树鸣。雨急了，潮涨了，空船在水上轻轻一横。
- 唐小诗：春潮带雨晚来急。急的是潮。渡口不该一直空着。
- 横舟精：野渡无人舟自横。自横最好。有人上船，诗就吵了。你还上不上？
- 唐小诗：上。船可以横。写船的人要靠岸。
- 横舟精：靠可以。对上了，这船才肯把桨还你。

过关：
- 横舟精：桨还了。秋夜有人散步，松子一落，朋友该还没睡。
- 旁白：空船舱底横着一把湿钥匙，自己不会正过来。
- 唐小诗：渡口我走过了。夜还长。

### 2. 空山夜

- 诗：《秋夜寄邱员外》
- 怪：松子精
- id：`tang-weiyingwu-2`

开场：
- 旁白：怀君属秋夜。散步咏凉天。空山里一颗松子掉下来，响得很清楚，人没有回来。
- 唐小诗：空山松子落。落就落。幽人应未眠——他想的那个人，该还醒着。
- 松子精：未眠。眠的是诗人。信写了一半，人被我收进松球里。你还寄不寄？
- 唐小诗：寄。夜可以凉。信要送到，人也要在。
- 松子精：送可以。对完，松子才肯裂开。

过关：
- 松子精：裂了。郡斋今夜冷，他忽然想起山里的道士，想送一瓢酒。
- 旁白：松子裂开，仁是一把小钥匙，香，像刚从树上掉下来。
- 唐小诗：信我记下了。酒我去送。

### 3. 全椒山

- 诗：《寄全椒山中道士》
- 怪：白石道
- id：`tang-weiyingwu-3`

开场：
- 旁白：今朝郡斋冷。忽念山中客。涧底有一捆荆薪，没人抱回去。落叶铺满空山，脚印没有。
- 唐小诗：涧底束荆薪，归来煮白石。石头当饭也行。找人比煮石急。
- 白石道：欲持一瓢酒，远慰风雨夕。酒我扣了。落叶满空山，何处寻行迹——迹在我袖里。
- 唐小诗：叶子可以满。迹要还。道士要回去，写酒的人也要回去。
- 白石道：回可以。对上了，这山才把落叶扫开一条缝。

过关：
- 白石道：缝开了。淮上有人重逢，十年没见，鬓都花了，还在笑。
- 旁白：荆薪里抽出一把钥匙，还带着雨和烟。
- 唐小诗：酒留下。故人我去见。

### 4. 淮上殿（Boss）

- 诗：《淮上喜会梁州故人》
- 怪：大魔王
- id：`tang-weiyingwu-boss`

开场：
- 旁白：江汉曾为客。殿里水气很重。韦应物被锁在淮上的雾里，对面像有一个老朋友，伸手却是空的。
- 唐小诗：相逢又十年。十年可以等。人不可以是雾。
- 大魔王：欢笑情如旧。旧。萧疏鬓已斑——斑的是霜。何因不归去？淮上对秋山。归不了。
- 韦应物：小诗。轻一点。渡口你已经走过了。把这首会完，雾会散，故人会实。
- 唐小诗：笑可以旧。人要真的。

过关：
- 大魔王：……这么闲最烦。胡天八月就下雪，像谁在树上开了一夜的花。
- 韦应物：去找岑参。马上要送人回京，先让他把雪写完。
- 唐小诗：雾散了。营我去。
