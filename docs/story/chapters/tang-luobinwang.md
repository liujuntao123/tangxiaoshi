# 骆宾王章

- 诗人：骆宾王
- 朝代：tang
- 钩子：鹅还会叫，写鹅的人空了
- 时代：初唐
- 标签：蒙学, 咏物
- 钥匙：2

## 开场

- 旁白：池塘里一排白鹅。脖子一弯，齐声叫。岸上的石桌上，只剩半片鹅毛。
- 唐小诗：鹅鹅鹅！这是我第一首会背的。陶渊明说从这儿进唐朝。
- 白鹅精：曲项向天歌。歌是我的。小孩也会唱？

## 关卡

### 1. 鹅池

- 诗：《咏鹅》
- 怪：白鹅精
- id：`tang-luobinwang-1`

开场：
- 旁白：白毛浮绿水。红掌一下一下拨，水花溅到石桌的白纸上，纸还是空的。
- 唐小诗：红掌拨清波。我会拨，也会背。
- 白鹅精：鹅鹅鹅。三声。少一声，这页就沉到池底。
- 唐小诗：曲项向天歌。项是脖子。你别把脖子伸进我本子里。
- 白鹅精：对上了，毛还你。对不上，你来给我梳毛。

过关：
- 白鹅精：……行。别踩红掌。易水那头风更冷，不是池塘。
- 旁白：一根鹅毛沉下去，又浮起来，毛管里是钥匙。
- 唐小诗：第一首还在。骆宾王小时候也是这么喊的吧。

### 2. 易水

- 诗：《易水送别》
- 怪：寒水怪
- id：`tang-luobinwang-2`

开场：
- 旁白：水很冷。岸上没人送别，风却像有人把帽子掀起来。
- 唐小诗：此地别燕丹。不是送我，是送一位壮士。
- 寒水怪：壮士发冲冠。冠我摘了。昔时人已没——没在水里。
- 唐小诗：今日水犹寒。寒我知道。人要上来。
- 寒水怪：上来可以。诗对完，水才肯让路。

过关：
- 寒水怪：水还寒。牢里有蝉，比鹅难听，比鹅更急。
- 旁白：一块冰化开，钥匙躺在中间。
- 唐小诗：送别的歌，我也要带上。

### 3. 蝉牢殿（Boss）

- 诗：《在狱咏蝉》
- 怪：大魔王
- id：`tang-luobinwang-boss`

开场：
- 旁白：殿里没有窗。只有蝉。骆宾王坐在阴影里，头上还戴着南冠。
- 唐小诗：西陆蝉声唱。蝉在唱，人不能只坐着。
- 大魔王：南冠客思深。深不深？不堪玄鬓影——你的头发还黑，他的诗要白了。
- 骆宾王：小诗。别看冠。把《在狱咏蝉》念出来，蝉会替我作证。
- 唐小诗：作证就作证。把人还池塘。

过关：
- 大魔王：……鹅还会叫。下一筐是田里的。汗比毛重。
- 骆宾王：去找李绅。盘里的饭，粒粒都是诗。
- 唐小诗：悯农。我会。谢谢鹅，谢谢蝉。
