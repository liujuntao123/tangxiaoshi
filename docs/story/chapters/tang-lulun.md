# 卢纶章

- 诗人：卢纶
- 朝代：tang
- 钩子：弓还在，夜是黑的
- 时代：中唐
- 标签：边塞, 组诗
- 钥匙：3

## 开场

- 旁白：关外没有灯。旗还立着，弓还上弦，写边塞的人不在营里。
- 唐小诗：王昌龄把边关的月还回来了。下一营该是卢纶。
- 金仆姑：千营共一呼。呼过了。人被呼走了。

## 关卡

### 1. 旗门

- 诗：《塞下曲·鹫翎金仆姑》
- 怪：金仆姑
- id：`tang-lulun-1`

开场：
- 旁白：鹫翎金仆姑。箭翎还亮。燕尾绣蝥弧——旗在风里拍。
- 唐小诗：独立扬新令。令在，发令的人不在。
- 金仆姑：千营共一呼。你呼一个我听听。
- 唐小诗：我不会发令。我会背诗。诗也是令。
- 金仆姑：令可以借。对上了，旗门才开。

过关：
- 金仆姑：门开了。林子里有弓响，别被草吓到。
- 旁白：箭翎削成钥匙，锋利得不敢握紧。
- 唐小诗：营还在。人在林子里。

### 2. 暗林

- 诗：《塞下曲·林暗草惊风》
- 怪：石棱怪
- id：`tang-lulun-2`

开场：
- 旁白：林暗草惊风。风一过，草像有虎。其实是弓。
- 唐小诗：将军夜引弓。箭在夜里飞，白天才找。
- 石棱怪：平明寻白羽。羽在我棱里。没在石棱中——你拔不拔？
- 唐小诗：拔。先对诗。对完，羽是钥匙。
- 石棱怪：拔错了会断。对对了才让你拔。

过关：
- 石棱怪：羽给你。今夜月黑，雁飞得很高。
- 旁白：白羽抽出来，杆是钥匙。
- 唐小诗：虎不是虎。人还在后头。

### 3. 雪原

- 诗：《塞下曲·月黑雁飞高》
- 怪：满弓精
- id：`tang-lulun-3`

开场：
- 旁白：月黑雁飞高。雪亮得像有月。单于的脚印乱，追的人没有。
- 唐小诗：单于夜遁逃。逃的不是诗人。诗人被你拦在雪里。
- 满弓精：欲将轻骑逐。逐得上吗？大雪满弓刀——刀都白了。
- 唐小诗：雪我不怕。弓刀上的诗更不能白。
- 满弓精：白可以。对完，雪才肯让马蹄。

过关：
- 满弓精：马蹄有了。营里在摆酒，金甲还响。
- 旁白：刀背上冻着一把钥匙，化一点才能用。
- 唐小诗：追到了。酒我闻一闻。

### 4. 野幕殿（Boss）

- 诗：《塞下曲·野幕敞琼筵》
- 怪：大魔王
- id：`tang-lulun-boss`

开场：
- 旁白：野幕敞琼筵。酒菜是冷的。卢纶被锁在金甲旁边，像刚从雪里回来。
- 唐小诗：羌戎贺劳旋。旋的是军，不是你抓人。
- 大魔王：醉和金甲舞。舞一个。雷鼓动山川——鼓你敲得动吗？
- 卢纶：小诗。别舞。把第四首念完，鼓自己会响。
- 唐小诗：山川会动。人要站起来。

过关：
- 大魔王：……边塞四首都还。城阙那边有人送朋友，话很硬。
- 卢纶：去找王勃。海内存知己，比千营一呼还齐。
- 唐小诗：知己我去找。营交给雪。
