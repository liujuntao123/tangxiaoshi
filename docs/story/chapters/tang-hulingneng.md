# 胡令能章

- 诗人：胡令能
- 朝代：tang
- 钩子：钓竿还在，招手的人不在
- 时代：中唐
- 标签：蒙学, 童趣
- 钥匙：2

## 开场

- 旁白：河岸青苔滑。一根小钓竿斜插着，没有小孩，只有一只蜻蜓。
- 唐小诗：李绅叫我轻轻问。这儿该有个蓬头小孩。
- 苔坐精：怕得鱼惊不应人。你一喊，鱼就没。

## 关卡

### 1. 苔矶

- 诗：《小儿垂钓》
- 怪：苔坐精
- id：`tang-hulingneng-1`

开场：
- 旁白：蓬头稚子学垂纶。苔上有一小屁股印，人已经没了。
- 唐小诗：侧坐莓苔草映身。他藏在草里？还是被你藏了？
- 苔坐精：路人借问遥招手。招手可以。开口不行。鱼怕吵。
- 唐小诗：那我不出声。我对诗。诗比问话轻。
- 苔坐精：不应人。应诗可以。对上了，竿还你。

过关：
- 苔坐精：鱼还在。芦花那边有车马，小孩更怕。
- 旁白：钓钩上挂着一把细钥匙，不响。
- 唐小诗：我会招手，不喊。

### 2. 芦花径

- 诗：《喜韩少府见访》
- 怪：芦藏精
- id：`tang-hulingneng-2`

开场：
- 旁白：草堂门开着。荷衣挂在墙上。儿童的脚印跑进芦花，就断了。
- 唐小诗：忽闻梅福来相访。来客是官，小孩没见过车马。
- 芦藏精：走入芦花深处藏。藏得好。你找不找得到？
- 唐小诗：笑著荷衣出草堂。主人该出来。小孩藏着就行。
- 芦藏精：车马是我变的。诗对完，芦花才分路。

过关：
- 芦藏精：路开了。堂前有绣样，黄莺会认。
- 旁白：芦花絮团成一把轻钥匙。
- 唐小诗：小孩可以藏。诗人不行。

### 3. 绣样殿（Boss）

- 诗：《绣样》
- 怪：大魔王
- id：`tang-hulingneng-boss`

开场：
- 旁白：日暮堂前花蕊娇。绣绷还在，针停着。胡令能被锁在花边里，像一针没绣完。
- 唐小诗：争拈小笔上床描。描的是花，不是锁。
- 大魔王：绣成安向春园里。园是我的。引得黄莺下柳条——莺呢？
- 胡令能：小诗。别弄乱针。把诗念完，黄莺会来认人。
- 唐小诗：莺来。人走。

过关：
- 大魔王：……小孩最烦。柳树倒好剪，剪柳的人在堤上。
- 胡令能：去找贺知章。他回家的时候，小孩也不认得他。
- 唐小诗：我认得。柳我去。
