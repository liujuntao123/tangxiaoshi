# 贺知章章

- 诗人：贺知章
- 朝代：tang
- 钩子：柳绿了，回家的人还在路上
- 时代：盛唐
- 标签：乡情, 咏物
- 钥匙：2

## 开场

- 旁白：堤上的柳绿得发亮。家门开着，镜子里没有人。
- 唐小诗：胡令能说小孩不认得回家的人。贺知章就在这条路上。
- 柳丝精：春风是剪刀。人被我剪走了。

## 关卡

### 1. 咏柳堤

- 诗：《咏柳》
- 怪：柳丝精
- id：`tang-hezhizhang-1`

开场：
- 旁白：碧玉妆成一树高。万条绿丝甩在脸上，像有人故意挡路。
- 唐小诗：不知细叶谁裁出。剪刀不是你的。
- 柳丝精：二月春风似剪刀。风是我请来的。你是小孩，也会裁？
- 唐小诗：我会背。万条垂下绿丝绦。绦还你，人还我。
- 柳丝精：绦可以还。人在回家的路上。对上了才放你过堤。

过关：
- 柳丝精：丝松开了。路上有个老先生，小孩围着笑。
- 旁白：一片细叶卷成钥匙，还带着春风。
- 唐小诗：回家的路，我陪他走完。

### 2. 回乡路

- 诗：《回乡偶书》
- 怪：乡音精
- id：`tang-hezhizhang-2`

开场：
- 旁白：少小离家老大回。路上有个老先生，小孩指着他笑，人却是假的。
- 唐小诗：乡音无改鬓毛衰。音还在，鬓是雪。
- 乡音精：儿童相见不相识。识不识？笑问客从何处来——你从何处来？
- 唐小诗：从田里来。从鹅池来。客是他，不是我。
- 乡音精：来得晚。诗对完，小孩才把路让开。

过关：
- 乡音精：路让了。镜湖那头水还是旧时的。
- 旁白：一缕乡音结成钥匙，听着像小时候。
- 唐小诗：不认得也没关系。诗认得。

### 3. 镜湖殿（Boss）

- 诗：《回乡偶书·其二》
- 怪：大魔王
- id：`tang-hezhizhang-boss`

开场：
- 旁白：离别家乡岁月多。贺知章被锁在镜湖边的空宅里，看着门前水。
- 唐小诗：近来人事半销磨。你磨的是人。
- 大魔王：唯有门前镜湖水。水还在。春风不改旧时波——波你改得了吗？
- 贺知章：小诗。水不改就好。把诗念出来，我就能再看一回。
- 唐小诗：春风不改。人也不许改没。

过关：
- 大魔王：……老家最烦。楼只有三层，有人偏要再上。
- 贺知章：去鹳雀楼。想看远，先把人找回来。
- 唐小诗：更上一层。我去。
