# 朱熹章

- 诗人：朱熹
- 朝代：song
- 钩子：方塘要活水，人要回来
- 时代：南宋
- 标签：读书, 活水, 春天
- 钥匙：3

## 开场

- 旁白：胜日寻芳泗水滨。无边光景一时新。春在，寻芳的人不在。
- 唐小诗：杨万里说水要活。朱熹把书当成塘。塘在，人空了。
- 寻芳精：等闲识得东风面。面是我。人不是。

## 关卡

### 1. 泗水滨

- 诗：《春日》
- 怪：寻芳精
- id：`song-zhuxi-1`

开场：
- 旁白：无边光景一时新。花一下子全开了。岸上有脚印，寻芳的人走到一半就断。
- 唐小诗：等闲识得东风面。面我识得。写春的人，我还没识到。
- 寻芳精：万紫千红总是春。总是我。你识得花，识不得人。人我收进风里了。
- 唐小诗：风可以把花吹开。不能把人吹没。把朱熹还岸上。
- 寻芳精：还不还，对上了，东风才肯把路指出来。

过关：
- 寻芳精：指了。半亩方塘像一面镜子，没有源头就会浊。
- 旁白：一朵小花压成钥匙，万紫千红挤在齿上。
- 唐小诗：春我识得了。塘边我去看水。

### 2. 方塘台

- 诗：《观书有感》
- 怪：鉴塘精
- id：`song-zhuxi-2`

开场：
- 旁白：半亩方塘一鉴开。天光云影在水里走来走去。书摊着，读书的人不在。
- 唐小诗：问渠那得清如许。清是因为活水。人被截走了，塘也会浊。
- 鉴塘精：为有源头活水来。源是我。我把源截了。你接得上吗？
- 唐小诗：接。水要活。人也要活。死水里照不见人。
- 鉴塘精：照不照得见，对完，源头才肯再漏过来。

过关：
- 鉴塘精：漏了。江边春水昨夜刚涨，大船自己会走。
- 旁白：一勺塘水冻成钥匙，清得能照见天。
- 唐小诗：活水记下了。船那头我去。

### 3. 武夷船

- 诗：《泛舟》
- 怪：艨艟怪
- id：`song-zhuxi-3`

开场：
- 旁白：昨夜江边春水生。大船轻得像一根羽毛。以前怎么推都不动，今天人却不在船上。
- 唐小诗：向来枉费推移力。不是船重。是水不够。现在水够了，人更该在。
- 艨艟怪：此日中流自在行。自在是我的。船轻了，我把诗人提走，更轻。
- 唐小诗：轻给船。人要自己坐着。自在不是空。
- 艨艟怪：空不空，对上了，桨才肯还你。

过关：
- 艨艟怪：桨还你。五月榴花亮得晃眼，这儿没有车马，花瓣倒在苔上。
- 旁白：一片船帮木削成钥匙，轻得像羽毛。
- 唐小诗：船会走了。没人来的那园子，我去。

### 4. 榴花殿（Boss）

- 诗：《题榴花》
- 怪：大魔王
- id：`song-zhuxi-boss`

开场：
- 旁白：五月榴花照眼明。枝间有小石榴。殿前没有车马。朱熹被锁在苍苔边上，书还摊着。
- 唐小诗：可怜此地无车马。没有人来，不是让你把人锁在这儿。
- 大魔王：颠倒苍苔落绛英。花自己会掉。源头我截过一次。你还要接？
- 朱熹：小诗。看书像看水。水活着，字才清。你把这首走完，车马不来也没关系，人要在。
- 唐小诗：在。塘还要清。

过关：
- 大魔王：……清最烦。云淡风轻那条路，有人偷闲学少年。
- 朱熹：去找程颢。活水看完了。他心里那点乐，也要回来。
- 唐小诗：乐我去找。源头不关。
