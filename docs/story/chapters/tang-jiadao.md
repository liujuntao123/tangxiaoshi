# 贾岛章

- 诗人：贾岛
- 朝代：tang
- 钩子：松下问童子，言师被抓走了
- 时代：中唐
- 标签：寻隐, 推敲
- 钥匙：2

## 开场

- 旁白：松树下站着一个小孩。他指指云，又摇头。药篓空着，山路像被谁擦掉了。
- 唐小诗：孟郊的马跑得太快。这儿该问一句。松下问童子。童子说：师父被抓走了。
- 云深精：言师采药去。不是采药。云把人吞了。

## 关卡

### 1. 松下

- 诗：《寻隐者不遇》
- 怪：云深精
- id：`tang-jiadao-1`

开场：
- 旁白：松下问童子。言师采药去。只在此山中。云一厚，处就没有了。
- 唐小诗：云深不知处。不知处，不是没有处。人在山里，不能只在云里。
- 云深精：不知处最好。药我采了。师我藏了。你一个小孩，问得出来吗？
- 唐小诗：问得出。童子会指。诗也会指。云让开就行。
- 云深精：让可以。对上了，这云才肯薄成路。

过关：
- 云深精：薄了。荒园夜里有僧，站在门前，推一下还是敲一下，想了好久。
- 旁白：童子掌心一枚松果钥匙，扎手，像刚从针里摘下来。
- 唐小诗：山我问过了。门我去听。

### 2. 幽居园

- 诗：《题李凝幽居》
- 怪：月下僧
- id：`tang-jiadao-2`

开场：
- 旁白：闲居少邻并，草径入荒园。鸟在池边树上睡。月在门上。有人举手，落不落下去。
- 唐小诗：鸟宿池边树。鸟睡了。僧敲月下门——是敲，还是推？他想了一夜。
- 月下僧：敲太响。推太没声。过桥分野色，移石动云根——门是我的。人在门后。你敲不敲？
- 唐小诗：敲。轻轻敲。门要开。想字的人要从门后出来。
- 月下僧：开可以。对完，这门才肯把月让进园里。

过关：
- 月下僧：让了。有人磨了十年剑，刃上有霜，还没试过。
- 旁白：门环上凝着一片月，月是钥匙，敲一下会轻轻响。
- 唐小诗：敲定了。剑我去看。

### 3. 剑阁殿（Boss）

- 诗：《剑客》
- 怪：大魔王
- id：`tang-jiadao-boss`

开场：
- 旁白：十年磨一剑。殿里很亮，刃上的霜还没试。贾岛被锁在剑匣旁边，手还保持着敲门的姿势。
- 唐小诗：霜刃未曾试。不是不试。今日把示君——不平的事就是抓人。
- 大魔王：谁有不平事？事是我做的。剑你拿得动吗？十年，你才几岁？
- 贾岛：小诗。不必试刃。推敲你已经听过了。把这首站稳，剑自己会亮，匣自己会开。
- 唐小诗：岁数不够。诗够。匣要开。

过关：
- 大魔王：……敲门最烦。巴山还在下雨，西窗的蜡烛结了泪，没人剪。
- 贾岛：去找李商隐。剑我收回来了。雨里还有一封信，归期没有，人得在。
- 唐小诗：门记下了。雨我去。
