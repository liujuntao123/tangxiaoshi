# 欧阳修章

- 诗人：欧阳修
- 朝代：song
- 钩子：笼子里的鸟还会叫，写鸟的人不在
- 时代：北宋
- 标签：鸟儿, 春, 自在
- 钥匙：2

## 开场

- 旁白：林子里画眉还在叫。金笼子也在叫。写鸟的人两头都不在。
- 唐小诗：王安石说笼里的叫不如林子里的叫。写这句话的人更不能关着。
- 金笼精：锁向金笼听。听得见，出不去。

## 关卡

### 1. 画眉林

- 诗：《画眉鸟》
- 怪：金笼精
- id：`song-ouyangxiu-1`

开场：
- 旁白：百啭千声随意移。山花红紫，树有高有低。笼子是金的，鸟不是。
- 唐小诗：始知锁向金笼听。金有什么好。叫是自己的才好听。
- 金笼精：不及林间自在啼。自在？林子里谁听得清。笼里又亮又近，不好吗？
- 唐小诗：不好。近不是自在。人关着，诗也会哑。
- 金笼精：哑不哑，对上了，笼门才从里面弹开。

过关：
- 金笼精：弹开了。亭前有人踏花，春都快老了，人还不在。
- 旁白：一根画眉羽编成钥匙，从笼缝里漏出来。
- 唐小诗：林子还给鸟。亭子我去找人。

### 2. 丰乐亭

- 诗：《丰乐亭游春》
- 怪：踏花精
- id：`song-ouyangxiu-2`

开场：
- 旁白：红树青山日欲斜。长郊草色绿到天边。亭前落花一层，脚印很多，写的人没有。
- 唐小诗：游人不管春将老。不管可以。不能把写春的人踩没。
- 踏花精：来往亭前踏落花。踏是我。花都老了，人还来。你也来踩吗？
- 唐小诗：我不踩。我把花让开。人要从花里站起来。
- 踏花精：站不站得起来，对完，落花才肯分路。

过关：
- 踏花精：路分了。二月的山城还没花，春风像走不到那儿。
- 旁白：一枚落花贴在钥匙上，被踩过又弹起来。
- 唐小诗：春会老。人不能老在笼子里。山城我去。

### 3. 山城殿（Boss）

- 诗：《戏答元珍》
- 怪：大魔王
- id：`song-ouyangxiu-boss`

开场：
- 旁白：春风疑不到天涯。殿像一座二月的山城，看不见花。欧阳修被锁在残雪边上，还说花会来。
- 唐小诗：二月山城未见花。未见不是没有。你把人藏在没花的地方，算什么。
- 大魔王：金笼才整齐。林子太乱。野芳虽晚——晚就晚，锁着不是更干净？
- 欧阳修：不须嗟。小诗。花开得晚也不必叹气。笼再金，也不如林子。你把这首走完，春风自己会到。
- 唐小诗：到。把笼打开。人回林子。

过关：
- 大魔王：……自在最烦。江上鲈鱼正鲜，船上那个人更好关。
- 欧阳修：去找范仲淹。别人只看见鱼美，他看见风浪。
- 唐小诗：风浪我不怕。鱼留给江。
