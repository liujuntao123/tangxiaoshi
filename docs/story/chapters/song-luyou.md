# 陆游章

- 诗人：陆游
- 朝代：song
- 钩子：山重水复，忽然又见村子，人却不在
- 时代：南宋
- 标签：村子, 梅花, 团圆
- 钥匙：3

## 开场

- 旁白：莫笑农家腊酒浑。丰年留客足鸡豚。酒在，客空了。
- 唐小诗：辛弃疾说路断了也会再开。柳暗花明又一村。村在，放翁不在。
- 疑路精：山重水复疑无路。路我叠上的。人我叠进去了。

## 关卡

### 1. 山西村

- 诗：《游山西村》
- 怪：疑路精
- id：`song-luyou-1`

开场：
- 旁白：山重水复疑无路。转过柳阴，花忽然明了。又是一个村子。箫鼓很近，人没有。
- 唐小诗：柳暗花明又一村。村会自己出现。人不会。人被你绕进山里了。
- 疑路精：从今若许闲乘月。月下可以敲门。你敲吧。敲到的是空。
- 唐小诗：空我不要。酒可以浑。待客的人要在桌边。
- 疑路精：在不在，对上了，山水才肯再让出一条路。

过关：
- 疑路精：让了。驿外断桥边有梅，开着没人管，雨还在下。
- 旁白：一滴腊酒渗进钥匙，浑，但是暖。
- 唐小诗：村子见到了。断桥那枝梅，我去守。

### 2. 驿外桥

- 诗：《卜算子》
- 怪：香故精
- id：`song-luyou-2`

开场：
- 旁白：驿外断桥边。寂寞开无主。黄昏了。风和雨一起打在梅上。
- 唐小诗：零落成泥碾作尘。泥可以踩。只有香如故——香还在，人不能碎。
- 香故精：无意苦争春。不争。一任群芳妒——妒是它们的事。人我收进泥里了。
- 唐小诗：泥里也要香。香在，人就要从泥里站起来。
- 香故精：站不站得起来，对完，雨才停，香才肯跟你走。

过关：
- 香故精：跟了。篱门外天亮以前最凉。河很长，山很高，有人朝北望。
- 旁白：一缕梅香粘在钥匙上，泥都碾不掉。
- 唐小诗：香如故。凉那头，我去望一口。

### 3. 篱门外

- 诗：《秋夜将晓出篱门迎凉有感》
- 怪：摩天精
- id：`song-luyou-3`

开场：
- 旁白：三万里河东入海。五千仞岳上摩天。篱门开着。南望的人，望了一年又一年，人却不在门边。
- 唐小诗：遗民泪尽胡尘里。不是吓人。是等。等军队把中原收回来。等的人不能没。
- 摩天精：南望王师又一年。一年我拖。再一年我也拖。你望得到边吗？
- 唐小诗：望不到边。我也望。望着，人就要在。
- 摩天精：在不在，对完，河才肯流，山才肯让路。

过关：
- 摩天精：让了。最后一张纸摊着。他还有一句话，要留给家里。
- 旁白：一粒河沙铸成钥匙，还望着北边。
- 唐小诗：望过了。纸那头，我轻轻进去。

### 4. 放翁殿（Boss）

- 诗：《示儿》
- 怪：大魔王
- id：`song-luyou-boss`

开场：
- 旁白：殿里一张纸。陆游被锁在床边，声音很轻，不像打仗，像交代事。
- 唐小诗：死去元知万事空。人走了，很多事就空了。但悲不见九州同——他只难过一件：天下还没团圆。
- 大魔王：万事空。空了就好。家祭无忘告乃翁——祭也是空。你一个小孩，也想告诉他？
- 陆游：小诗。别哭。王师北定中原日，家里祭的时候，记得告诉我一声。你把这首走完，纸不会白。
- 唐小诗：不白。我会告诉你。诗还在。

过关：
- 大魔王：……嘱咐最烦。零丁洋上还有一颗心，死死指着南，不肯偏。
- 陆游：去找文天祥。家祭记下了。最后那颗丹心，比我更硬。
- 唐小诗：记下了。南方那头，我去。
