# 刘禹锡章

- 诗人：刘禹锡
- 朝代：tang
- 钩子：燕子还在，王谢堂前空了
- 时代：中唐
- 标签：怀古, 豪迈, 山水
- 钥匙：4

## 开场

- 旁白：朱雀桥边野草开花。乌衣巷口夕阳斜着。燕子进了平常人家，旧堂是空的。
- 唐小诗：杜牧说燕子会带路。旧时王谢堂前燕——燕还在，写燕的人空了。
- 巷口燕：飞入寻常百姓家。家换了。人被我衔走了。

## 关卡

### 1. 乌衣巷

- 诗：《乌衣巷》
- 怪：巷口燕
- id：`tang-liuyuxi-1`

开场：
- 旁白：巷子窄。夕阳只剩一条。堂前的梁上有新泥，燕子叫，人不答。
- 唐小诗：旧时王谢堂前燕。燕认得路。路不是用来叼人的。
- 巷口燕：堂前空了。空得好。富贵会旧，燕子不旧。你要旧的还是要人？
- 唐小诗：要人。燕可以继续住平常人家。
- 巷口燕：住可以。对上了，巷口才把夕阳让开。

过关：
- 巷口燕：让了。秋天有人偏不哭，还说秋比春好。
- 旁白：燕窝里掉下一把钥匙，还温着，沾一点新泥。
- 唐小诗：旧事我记下了。晴空我去。

### 2. 秋晴台

- 诗：《秋词》
- 怪：碧霄鹤
- id：`tang-liuyuxi-2`

开场：
- 旁白：台很高。天蓝得发硬。一只鹤把云排开，像在给诗让路。
- 唐小诗：自古逢秋悲寂寥。别人秋天爱叹气。他不叹。
- 碧霄鹤：我言秋日胜春朝。胜。晴空一鹤排云上——上的是我。你的诗情到碧霄了吗？
- 唐小诗：到了。秋天也可以很亮。人更要亮着回来。
- 碧霄鹤：亮可以。对完，鹤才肯把云铺成路。

过关：
- 碧霄鹤：路铺了。江上杨柳青青，有人踏歌，一边出太阳一边下雨。
- 旁白：一截鹤羽削成钥匙，直指天，拿着像要飞。
- 唐小诗：秋我不服输。歌我去听。

### 3. 竹枝江

- 诗：《竹枝词》
- 怪：踏歌精
- id：`tang-liuyuxi-3`

开场：
- 旁白：杨柳青青江水平。东边出太阳，西边在下雨。岸上踏歌的脚印，一串就断。
- 唐小诗：闻郎江上踏歌声。歌还在跳。唱歌的人跟写歌的人，都不见了。
- 踏歌精：道是无晴却有晴。晴是天气，也像心里那点亮。你有没有晴？
- 唐小诗：有。一边雨一边太阳，也可以算晴。人要回来踏。
- 踏歌精：踏可以。对上了，这江才肯把歌还你。

过关：
- 踏歌精：歌还了。黄河弯了九道，浪在淘沙，沙里有金。
- 旁白：半边干半边湿的柳叶，叶脉咬成钥匙齿。
- 唐小诗：晴我带走了。沙我去淘。

### 4. 黄河曲

- 诗：《浪淘沙》
- 怪：浪淘怪
- id：`tang-liuyuxi-4`

开场：
- 旁白：九曲黄河万里沙。浪把风簸到天边。岸上站过一个人，脚印被淘平了。
- 唐小诗：浪淘风簸自天涯。沙可以淘。人不是沙，淘不走。
- 浪淘怪：淘尽狂沙始到金。金在我肚子里。诗在不在你肚子里？
- 唐小诗：在。金你留。写浪的人还我。
- 浪淘怪：留可以。对完，浪才肯把金吐出来。

过关：
- 浪淘怪：吐了。洞庭那面镜子还没磨亮，盘子里有一颗青螺。
- 旁白：沙里淘出一把金钥匙，边还毛着，握着烫手。
- 唐小诗：金我不要。镜子我去。

### 5. 洞庭殿（Boss）

- 诗：《望洞庭》
- 怪：大魔王
- id：`tang-liuyuxi-boss`

开场：
- 旁白：殿像把湖搬进来。湖光秋月两相和。刘禹锡被锁在一面没磨亮的镜子前，远处一颗青螺。
- 唐小诗：潭面无风镜未磨。没风也好。人要站在岸上自己看。
- 大魔王：遥望洞庭山水翠。翠的是山。白银盘里一青螺——螺是我扣下的。你端得动这只盘吗？
- 刘禹锡：小诗。秋天你已经没哭。把这首望完，镜子会亮，螺会还山。
- 唐小诗：盘是湖。螺是山。人都要回来。

过关：
- 大魔王：……秋还不哭，最烦。千山没有鸟了，船上还像有一个人。
- 刘禹锡：去找柳宗元。他被赶到很远的地方，江心更冷，诗更清。
- 唐小诗：镜子亮了。雪我去。
