# 辛弃疾章

- 诗人：辛弃疾
- 朝代：song
- 钩子：稻花香里，说丰年的人不在
- 时代：南宋
- 标签：稻花, 灯火, 想护家
- 钥匙：3

## 开场

- 旁白：明月别枝惊鹊。清风半夜鸣蝉。稻花香里蛙声一片，没有稼轩。
- 唐小诗：李清照说不能只有丰年没有人。辛弃疾能文能武。人被抓了，我也打回去。
- 稻香精：听取蛙声一片。声是我。说丰年的人是我藏的。

## 关卡

### 1. 黄沙道

- 诗：《西江月》
- 怪：稻香精
- id：`song-xinqiji-1`

开场：
- 旁白：稻花香里说丰年。七八个星在天外。两三点雨在山前。旧时茅店还在，人忽然不见。
- 唐小诗：路转溪桥忽见。见的该是他。见的是空。
- 稻香精：旧时茅店社林边。边是我守的。丰年我能说。人我偏不说。你听得见蛙吗？
- 唐小诗：听得见。蛙说丰年。丰年要人在田里。
- 稻香精：在不在，对上了，溪桥才肯转出那个人。

过关：
- 稻香精：转了一半。元宵灯火像花千树，那人该在最暗的地方。
- 旁白：一颗稻粒胀成钥匙，香得蛙都跟着叫。
- 唐小诗：丰年听见了。灯火那头我去寻。

### 2. 元宵巷

- 诗：《青玉案》
- 怪：阑珊精
- id：`song-xinqiji-2`

开场：
- 旁白：东风夜放花千树。星像雨一样被吹落。宝马香车过完了，最暗的那一角没有人。
- 唐小诗：众里寻他千百度。我寻了。蓦然回首——灯火阑珊处，也不见他。
- 阑珊精：那人却在灯火阑珊处。处是我。暗是我。你看灯，看热闹，看得到人吗？
- 唐小诗：热闹不是他。暗处才是。把暗处的人还我。
- 阑珊精：还不还，对完，残灯才肯亮一寸。

过关：
- 阑珊精：亮了。醉里有人挑灯看剑，梦里号角连营。
- 旁白：一盏残灯做成钥匙，火在最暗的那一头。
- 唐小诗：寻到暗处了。剑那头，我醒着去。

### 3. 连营帐

- 诗：《破阵子》
- 怪：的卢精
- id：`song-xinqiji-3`

开场：
- 旁白：醉里挑灯看剑。梦回吹角连营。马快得像飞。弓响得像雷。沙场上没有将军。
- 唐小诗：他想打仗，是想把家护住。不是爱打。梦可以有。人要从梦里回来。
- 的卢精：马作的卢飞快。快是我。了却君王天下事——事你一个小孩了却得了吗？
- 唐小诗：了却不了。我能把人喊醒。可怜白发生，白了也要在。
- 的卢精：在不在，对上了，马才肯停，角才肯歇。

过关：
- 的卢精：歇了。茅檐低小，溪上有青草，小孩在剥莲蓬。
- 旁白：一寸剑气凝成钥匙，灯花还爆着。
- 唐小诗：梦我看见了。茅屋那头，仗也可以不打。人要在。

### 4. 茅檐殿（Boss）

- 诗：《清平乐》
- 怪：大魔王
- id：`song-xinqiji-boss`

开场：
- 旁白：茅檐低小。溪上青青草。辛弃疾被锁在醉里的灯下。外头有个小孩卧着剥莲蓬。
- 唐小诗：最喜小儿亡赖。赖可以。茅屋要留。人更要留。
- 大魔王：醉里吴音。村就够了。剑可以收。你非要又丰年又打仗？小孩剥莲蓬，关你什么。
- 辛弃疾：小诗。茅屋要留。家也要护。小孩剥莲蓬的地方，不能丢。你把这首走完，灯会醒。
- 唐小诗：醒。莲蓬留给小孩。人还田里。

过关：
- 大魔王：……护家最烦。山西村酒还温着，山重水复，有人会迷路。
- 辛弃疾：去找陆游。稻花还香。村子那头，路断了也会再开。
- 唐小诗：莲蓬记下了。村我去。
