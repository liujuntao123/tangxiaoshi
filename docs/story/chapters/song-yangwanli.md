# 杨万里章

- 诗人：杨万里
- 朝代：song
- 钩子：小荷才露尖尖角
- 时代：南宋
- 标签：荷花, 蜻蜓, 小孩
- 钥匙：3

## 开场

- 旁白：泉眼无声惜细流。小荷才露出一个尖。蜻蜓立着，写荷的人不在。
- 唐小诗：范仲淹说小孩能看见的也不能空。杨万里最会写这种小东西。
- 泉眼精：细流我吝啬。人我更吝啬。

## 关卡

### 1. 小荷池

- 诗：《小池》
- 怪：泉眼精
- id：`song-yangwanli-1`

开场：
- 旁白：树阴照水爱晴柔。水很浅。小荷才露尖尖角，上头一只蜻蜓，下面没有人。
- 唐小诗：早有蜻蜓立上头。立可以。写立的人不能被你按进泥里。
- 泉眼精：惜细流。惜是我。这么小的池，也要诗人？你看得清尖尖角吗？
- 唐小诗：看得清。小的更要在。大人老爱看大的。
- 泉眼精：看不看得清，对上了，泉眼才肯再漏一滴。

过关：
- 泉眼精：漏了。六月的西湖更满，莲叶接到天上。
- 旁白：一滴泉眼凝成钥匙，细得几乎看不见。
- 唐小诗：小荷记下了。大荷那头我去。

### 2. 净慈寺

- 诗：《晓出净慈寺送林子方》
- 怪：碧莲精
- id：`song-yangwanli-2`

开场：
- 旁白：毕竟西湖六月中。风光不与四时同。莲叶接到天边，荷花红得不像平时。
- 唐小诗：接天莲叶无穷碧。碧到天。映日荷花别样红——人被你映到哪里去了。
- 碧莲精：别样红。红是我。四时都不如我。你一个小孩，也想来送人？
- 唐小诗：送。林子方要走，杨万里要在岸上看。看的人不能没。
- 碧莲精：没不没，对完，莲叶才分开一条船路。

过关：
- 碧莲精：分开了。新市那条小径，小孩追黄蝶，追着追着人没了。
- 旁白：一张荷叶托着钥匙，红得跟平时不一样。
- 唐小诗：别样红我看见了。黄蝶那头，我也追。

### 3. 徐公店

- 诗：《宿新市徐公店》
- 怪：菜蝶精
- id：`song-yangwanli-3`

开场：
- 旁白：篱落疏疏一径深。树头新绿还没成阴。儿童急走追黄蝶，追到菜花里，只剩花粉。
- 唐小诗：飞入菜花无处寻。蝶会藏。写小孩的人不会自己藏进花里。
- 菜蝶精：无处寻。寻是你的事。我飞，我黄，我躲。诗人我顺手卷走了。
- 唐小诗：卷回来。小孩可以追蝶。诗人要站在径上。
- 菜蝶精：站不站得住，对上了，菜花才把黄还出来。

过关：
- 菜蝶精：还了一半。今春本该好好玩，风白吹了，人被关在病里。
- 旁白：一只黄蝶翅膀印在钥匙上，一闪就想躲进菜花。
- 唐小诗：蝶我找到了。春天不高兴的那头，我去。

### 4. 诚斋殿（Boss）

- 诗：《伤春》
- 怪：大魔王
- id：`song-yangwanli-boss`

开场：
- 旁白：准拟今春乐事浓。殿里一滴东风都没有。杨万里被锁在小池边上，还想看蜻蜓。
- 唐小诗：依然枉却一东风。风不是白的。你不许把春天关掉。
- 大魔王：年年不带看花眼。不是愁中即病中——愁着、病着，花开给谁看？空了更好。
- 杨万里：小诗。蹲下来。尖尖角还在。你把这首走完，东风会再来一次。
- 唐小诗：来。把乐事还给他。

过关：
- 大魔王：……小孩最烦。半亩方塘要活水，有人把书当成塘。
- 杨万里：去找朱熹。蜻蜓看完了。水要活，人要回来。
- 唐小诗：活水我懂一点。我去塘边。
