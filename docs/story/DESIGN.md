# 正式版内容设计

给小学、初中玩。外在打怪过关，内在用诗文答题。内容以 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) 为主，蒙学缺篇用公版原文补在 `canonical.py`。

## 主线

大魔王抓的是**人**。诗住在人身上；人不在，纸会变白。唐小诗从河边的歌谣追到宋词，一章救出一位诗人。

| 朝 | 这一朝在讲什么 | 怎么开门 |
| --- | --- | --- |
| 先秦 | 歌从嘴里被抽走。采诗官的本子空了。 | 一开始就开 |
| 汉魏 | 有名字更好抓。乐府还在口头，曹操看海，曹植煮豆，陶渊明要回家种地。 | 先秦救出至少一位 |
| 唐 | 人人会背的那些先丢。从咏鹅、悯农走到李白杜甫，收到李商隐的夜雨。 | 汉魏救出至少一位 |
| 宋 | 词也是诗。收到陆游的示儿、文天祥的零丁洋：纸可以白，心里的诗不行。 | 唐救出至少一位 |

以后加元、清：只加朝代和章，不改存档字段。

## 数据分层

```
朝代 dynasty          可扩展：元、清
  └── 诗人章 chapter  一章救一人；以后可加「边塞合章」
        └── 关卡 level 一关一首诗 + 一只怪 + 独有对白
```

三种玩法仍共用一份诗文（ADR-0004）：

- 历险：`story.json` 编好的关
- 练习：`bank.json` 全部（蒙学 + 名篇，不是五万首）
- 无尽：只抽历险已解锁的诗

诗文带 `dynastyId` / `form` / `source` / `theme`。以后按诗体、主题、朝代做新玩法，不必再拆题库。

## 题目

四选一，只有四种：下一句、诗名、诗人、诗在写什么。含义用小孩能懂的一句，干扰项也是诗意错法，不用「在城里买菜」。

## 插画

- 场景 6 张循环：月 / 水 / 春 / 楼 / 江 / 殿。关卡靠地名和对白区分，不靠新底图。
- 妖怪 6 套贴图循环，**名字每关独有**。
- 诗人立绘一章一张，成就卡用同一张。
- 大魔王每章最后一关都出场，对白不重复。

## 成就

- 诗人卡：救出该章诗人
- 朝代卡：救出该朝全部诗人
- 挑战：滴水不漏、十连击

不加图鉴。收集物就是这些。
