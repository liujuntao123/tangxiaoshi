# 玩法重做落到诗卡体系：诗签/连击/收句/诗印

2026-09，本地「玩法重做」（连击/诗签/收句反馈/评级结算，原设计针对旧关卡体系，
见 `docs/game-design.md`）与上游「卡片式环游重构」（ADR-0011..0014）合并。
世界观看 0011：作者只是出题人，没有妖怪、血条与出招受击；本 ADR 只把玩法重做里的
**答题手感与成长反馈**移植到诗卡上。

## 决策

1. **答题显式状态机**：每张诗卡一轮 `loadout → battle → resolving → battle … → result`。
   作答后不再定时自动切题，而是给出结算快照（Resolution），玩家点「收句」才推进；
   答错展示正确答案与其相邻诗句（`poemContextFor`），不做长篇解析。
2. **诗签三选一（tour 专属）**：进入答题先选一枚——明心（隐去两个错项）、
   护卷（首次答错不灭灯笼但仍断连）、回响（首次答对后下一题额外加分加诗气）。
   均一次性；练习模式无诗签。
3. **连击/诗气/连携只做加分与反馈**：得分 = 100 + min((连击-1)×25, 100) + 连携 100；
   诗气条答错清零、不落存档；连击每达 3 的倍数点亮下次「连携」。不改变
   「答对 60% 通过、灯笼灭完失败」的上游通关判定。
4. **诗印评级与历史最佳**：每张诗卡记录 1-3 印（3 印 = 全程不灭灯笼且零失误，
   护卷挡下也算失误）、最高得分与最高连击，重玩只升不降（`poemRecords`）；
   结算页展示「新纪录/诗印提升/首次通关」，通关后可「再战提分」。
   成就体系仍是 0013 的三类全通制，不新增挑战成就。
5. **首页「继续环游」**：主按钮定位环游顺序（文集→章→卡）里最早一张未通关诗卡；
   全部通关时改为「再战提分」定位最后一张。附诗印/总分/无尽最高连对三项真实统计。
6. **无尽**：题池仍为全部已编译题（0011）；答题节奏与环游同款（收句/连击计分/
   诗句上下文），连对与得分分别刷新双最佳（得分是连击加权分，不再是连对数）。
7. **存档**：`PlayerSave` 在 v2 五字段上追加 `poemRecords`（诗卡历史最佳）与
   `totalScore`（环游累计得分），`migrations/0004_poem_records.sql`；
   读取端统一 `normalizeSave` 规范化（缺字段/脏数据回退默认值），规则函数集中在
   `src/lib/game/rules.ts` 并有纯函数测试（`node --test`）。

## 结果

- 答题页（`poem-quiz.tsx`）与无尽页共用一套反馈节奏与计分口径；练习模式同样
  「收句」推进，另保留「先看答案」。
- 环游章节页显示章节诗印合计，作者页诗卡角标显示该卡诗印（0-3）。
- 战斗包装（妖怪立绘/出招受击/血条）不回归；`/ui/choice-on.png` 等旧素材不复活。
