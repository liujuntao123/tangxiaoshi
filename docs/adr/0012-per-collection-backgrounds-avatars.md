# 每文集 5 张专属背景 + 各维度形象，废除共享场景池

旧方案是 20 张共享场景池按关卡 id hash 抽一张，画面与诗文内容无关，且朝代地图已随卡片式重构废除。
选择按维度配置素材：

- **全局背景 7 张**：首页 1 + 四主页面 3（无尽/练习/成就）+ 环游层级 3（文集列表/章节页/作者页；
  环游主页面=文集列表，共用一张）。
- **文集背景每集 5 张**：问答页使用；每张诗卡按诗 id 稳定绑定其中一张（同诗不变、换诗换图）。
- **形象**：文集（拟物书函+意象）、朝代（风物徽章）、章节（一套 10 张通用书签，按章序 mod 10 循环）、
  作者（Q 版立绘一人一张）、主角唐小诗（默认/欢呼/沮丧三形态）。
- 风格统一：古风 Q 版儿童绘本、青绿+米白限色、非背景类透明背景；流程规范见 docs/art.md。

**Status:** 取代 ADR-0006 中「场景 6 张循环」的实现方式（古风绘本风格基调仍有效），并取代 AGENTS.md 旧版「场景池复用」条目。
