# 0017 — 远征与文集分家：/tour 只留墨路，文集迁 /library

日期：2026-09-07（入口拆分）

## 背景

墨潮远征上线后，`/tour` 一个路由同时承担两种身份：无参数 = 墨路选择（主线），`?view=library` = 诗集资料库（浏览）。文集 → 章节 → 作者 → 诗卡层级也仍挂在 `/tour/$collectionId…` 之下。玩家走查（2026-09）反馈：

- 首页「继续远征」在未择墨路时落到 `/tour` 择路页，与玩家预期的「目标诗页」不符，体感像「没跳转」；
- 文集浏览与远征择路共用一个页面、一个 URL 空间，页内切换按钮、返回目标互相纠缠，职责重复；
- 从文集点进诗卡答题不推进远征节点，两条进度线在同一入口下并行，因果关系不明。

## 决策

1. **主线只保留一个入口**：首页远征台主按钮是唯一主线入口。当前节点已择墨路 → 「继续远征」直达 `/play/$poemId?route=&node=` 续修；未择墨路 → 按钮诚实显示「去择墨路」进 `/tour`；已收官 → 「再启远征」；新档 → 「点亮第一盏诗火」。
2. **`/tour` 只承载远征**：删除 `?view=library` 视图切换与页内文集网格；墨路选择页在当前节点已领诗卡时提供「续修本页」快捷，保证从首页绕到 `/tour` 的玩家一键回到原诗卡。
3. **文集独立成库**：新增 `/library` 路由挂诗集资料库，文集 → 章节 → 作者 → 诗卡层级整体迁至 `/library/$collectionId…`；底部导航「文集」直达。资料库内答题照常写入 `PlayerSave`（通关、诗印、最佳分），但不触碰远征状态——它定位是资料浏览与收集，不是主线。
4. **旧路径重定向**：`/tour/$collectionId(/$chapterId(/$authorId))` 保留为壳路由，`beforeLoad` 重定向到 `/library` 对应层级，旧书签/PWA 深链不断链。

## 后果

- URL 空间与信息架构一致：`/tour` = 远征，`/library` = 资料库，`/practice` = 诗库练习，互不共享可变状态。
- 「继续远征」的三种去向（答题 / 择路 / 重启）全部由按钮标签与说明文字明示，消除「点了没反应」的误读。
- 资料库与远征的进度关系在 ADR-0016 已有明确取舍（远征分数与资料库重战分数共享永久成绩口径），本篇不改变该口径。
- 旧深链多一跳客户端重定向，量级可忽略。
