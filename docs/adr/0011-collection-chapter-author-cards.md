# 环游按「文集→章节→作者→诗卡」组织，卡片式，全开放

旧主线是「朝代→作者章→关卡组」+ 2.5D 地图 + 顺序解锁，与抓取来的 poetry-site 数据集
（11 文集 / 98 章节 / 2155 首，天然是 文集→章节→诗）对不上，地图节点也无法承载词类文集。
选择直接采用数据源的层级：**文集 → 章节 → 作者 → 诗卡**，全部卡片式呈现，不做地图；
环游内部**全开放无门控**——任意诗卡随时可玩，推进感交给成就收集。

- 诗卡（一首诗）是问答单位：每诗 5 题（docs/content-rules.md），换诗换文集背景。
- 未编译文集在环游/练习中锁定展示（「待开放」），看得见全集结构。
- 介绍/序章（无作者无诗句）不入库。
- 无尽 = 已编译全部题池随机；练习 = 三轴筛选（文集-章节 × 作者 × 朝代）全开。

**Status:** 取代 ADR-0003（按诗人分章+朝代门）与 ADR-0007（直白关卡名+钥匙：关卡/钥匙/妖怪概念随地图一起废除）。
ADR-0005 的「解锁门控」部分由本篇取代（练习全开、无尽全池仍有效）。地图相关的 UI 红线一并作废。

**当前入口修订（ADR-0016 / ADR-0017）：**本篇定义的层级仍是诗集资料库的内容层级，但 `/tour` 已整体让位给墨潮远征的墨路选择；文集层级自 ADR-0017 起迁到独立的 `/library`（旧 `/tour/$collectionId…` 深链重定向过去），不再是主线入口。
