# 学段难度分档：50 关五档循序渐进

日期：2026-09-07
状态：有效（修订 [0018](0018-level-based-expedition.md) 的「无难度维度」条款）

## 背景与问题

ADR-0018 把主线定为 50 关平铺、无难度维度：全部诗按玩家种子洗牌后顺序切段，第 1 关可能抽到高中文言文，第 50 关也可能抽到一年级绝句。「内容差异由随机抽题自然产生」对成人无关痛痒，但目标玩家是小学和初中生——开局就撞上长篇文言文会直接劝退，难度也没有随远征推进形成任何叙事感。

数据侧已具备分级条件：教科书选诗（33 章 327 首入库）的章节标题自带学段/年级（小学一年级上册 → 高中三年级下册），其余文集可用「蒙学属性 + 篇幅」作稳定代理。需要回答：怎么定档、怎么铺关、怎么在界面上表达。

## 决策

1. **五档学段难度，每 10 关一档**。`difficulty` 1–5 = 小学·低 / 小学·中 / 小学·高 / 初中 / 高中；第 1–10 关只出 T1 的诗，11–20 关 T2……41–50 关 T5。标签就是学段词，直白、零学习成本，延续 0018 的「规则直白」支柱。
2. **编译期定档，规则唯一权威在 `docs/content-rules.md`**。
   - 教科书选诗：按章节标题推导——小学一二年级 → T1、三四年级 → T2、五六年级与小学文言文 → T3、初中（含初中文言文）→ T4、高中（含高中文言文）→ T5。
   - 其他文集：基础档（三字经/声律启蒙 1，蒙学唐诗 2，千家诗/唐诗三百首 3，古诗十九首/南唐二主词/诗经/宋词三百首 4，花间集 5）+ 篇幅修正（含标点字数：蒙学与启蒙读本的短篇经典下探 T1，长篇上探更高档，阈值见 content-rules）。
   - 编译进 `bank.json` 每诗 `difficulty` 字段（契约 v4），运行时不推导。
3. **关卡只用自己的档，不足就近补足**。`buildTierBands`（levels.ts）把全部诗分档：每档需要 130 首（10 关 × 13 首）；本档不足时按 +1、−1、+2、−2… 的顺序从邻档按常见度就近补足，补足占用的诗登记为已用——同一首诗只进一个档，全局 50 关题目零重复不被破坏。当前数据仅 T2（72 首）触发补足，从 T3 补 58 首（优先教材篇目）。
4. **档内按「学习常见度」铺位：教材篇目严格前置**。篇幅相近不等于常见——千家诗里的冷门五绝和《静夜思》一样短，但只有后者人人学过。因此每诗带 `studyRank` 常见度序：0 教材篇目、1000 通识读本（三字经/声律启蒙/蒙学唐诗/千家诗/唐诗三百首）、2000 经典（古诗十九首/南唐二主词/诗经/宋词三百首）、3000 雅致（花间集）。档内出题顺序 = 常见度分组依次铺开（组间顺序全服一致），组内做玩家专属洗牌：第 1 关全部是教材篇目（春晓、山行、赠汪伦……），生僻诗只会出现在每档末尾；组内洗牌保证不同玩家的每关诗单互不相同（防透题承诺保留在诗单粒度），同一玩家题目永远固定，重打同关同题。
5. **界面用最少的字标学段**：关卡列表卡的状态行直接显示学段标签（替代原「可挑战」文案，未解锁卡显示「学段 · 未解锁」）；答题开场面板一行「本关诗文 · 小学·低」；答题题卡与作答报告的出处行尾追加「· 学段」。不加进度条、不加配色系统、不加弹窗教学。
6. **难度档不影响其他入口**。诗卡、诗库、无尽模式继续用全库题池；学段与常见度只是诗卡的数据字段，不做筛选门控（未来若要「按学段练习」，另立 ADR）。

## 后果

- **开局体验可控且亲切**：第 1 关全部是教材篇目（《春晓》《山行》《赠汪伦》这一级别），每档由「学过的」走向「没学过的」，生僻诗只出现在档尾。
- **常见度是近似分级**：非教科书诗按文集通识程度分组（如花间集整体落在雅致组），是难度语义不是教材事实；文档与界面都不声称「对应某册教材」。同一常见度组内不保证年级顺序（组内洗牌）。
- **每档只用品类最合适的 130 首**：档内超出 130 首的部分（如 T3 的 471 首中较长的文言）不进主线关卡，仍在诗卡/诗库/无尽可用；这保证关卡内的常见度梯度稳定。
- **防透题与防重复的口径**：「不同玩家互不相同」落在每关诗单粒度（常见度组内玩家专属洗牌，组间顺序一致）；「关卡之间零重复」依靠档间登记不重叠，仍由测试直测（全 50 关 650 题零重复）。
- **篇幅不再决定档内顺序**：常见度压过篇幅（教材长文早于生僻短诗出现）；这是走查后的有意取舍——对目标玩家，「学过与否」比「长短」更接近真实难度。
- 存档结构零迁移：难度与常见度只影响出题，`levelStars` / `items` 口径不变；旧存档的星星只升不降。
