# 墨潮远征：三节点短局骨架

- 日期：2026-09-06
- 状态：有效
- 取代：主入口和远征玩法部分取代 ADR-0011、0015 的首页/继续环游口径；不取代其内容层级、题型、诗卡成绩规则。

## 背景

上一版把题库组织成“文集 → 章节 → 作者 → 诗卡”，并在诗卡内加入诗签、连击、收句和诗印。它解决了答题节奏问题，但首页和 `/tour` 仍然是资料目录，玩家缺少路线风险、短期资源和下一步决策。

## 决策

1. 首页主循环改为“墨潮远征”。首页是远征台，主按钮进入 `/tour` 的墨路选择；文集 → 章节 → 作者 → 诗卡保留为诗集资料库。
2. 一次远征最多三个节点。每个节点提供三条确定性路线候选，并从真实 `POEMS` 题库锁定一张诗卡：
   - 青灯小径：从未通关诗卡池优先选择；节点成功后额外回复 1 盏诗火。
   - 风雨险滩：从已通关诗卡池优先选择；每题正确额外 `+50` 分。
   - 无名残卷：从全部诗卡池选择；完成后可从三种修页奖励中选择。
3. 远征诗火初始 3、上限 4。远征答题把诗火作为当前诗卡的机会灯笼；答错通常损失 1 盏，失败后可重燃并重走节点。
4. 节点完成后可选择修页奖励：续灯（立即增加 1 盏诗火，受上限限制）、磨墨（下一节点首题答对 `+100` 分）、听句（下一节点开局显示第一行诗文）。普通路线提供二选一，无名残卷提供三选一。
5. 远征进行时状态由 `src/lib/game/expedition.ts` 管理，使用 `localStorage` key `tangxiaoshi.expedition.v1`。读写经过 normalize 并静默处理浏览器存储失败。它不是账号云存档：不跨设备、不跨浏览器，也不按用户 ID 隔离。永久诗卡成绩、诗印、总分、成就和无尽成绩仍由 `PlayerSave` 保存。
6. 远征终局只把“诗声复明”和“带伤归卷”写入远征状态的 `finished`；“墨潮未退”是本次节点失败的结算面板语义，失败后状态回到当前节点待攻略，不把失败远征永久锁死。
7. 远征路线加成会进入本次诗卡的 `score`，并随现有 `applyPoemWin` 进入 `poemRecords.bestScore` 与 `totalScore`。因此远征分数与资料库重战分数共享永久成绩口径；这是当前实现的明确取舍，未来若要区分必须增加独立记录字段和迁移。

## 不变部分

- 每张诗卡仍为 5 题，60% 及格；题型和内容生成规则见 `docs/content-rules.md`。
- 诗签明心、护卷、回响仍是当前诗卡的一轮一次性能力。
- 答错后必须阅读结果并主动点击“收句”；练习、墨潮试炼和资料库路径继续保留。
- 不恢复妖怪、血条、钥匙、旧地图门控、抽卡、付费货币或排行榜。
