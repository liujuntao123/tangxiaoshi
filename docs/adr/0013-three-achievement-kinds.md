# 成就只有文集/作者/朝代三类，全通制

旧成就 = 信物（poet/dynasty）+ 挑战（滴水不漏/十连击），绑定旧的章节/血条概念。
选择收敛为**三类**，全部按通关进度自动达成，不做隐藏挑战：

- **作者成就**：通关该作者全部诗卡（`author-{id}`）
- **文集成就**：通关该文集全部诗卡（`collection-{id}`）
- **朝代成就**：通关该朝代**已上线**的全部诗卡（`dynasty-{id}`）；以后新文集上线不回收已发成就

命名 = 直白主标 + 雅致副标（如「遇见李煜·词中之帝」「读罢南唐二主词·一江春愁」「走遍五代·五代词心」）。
挑战类成就删除，无尽模式激励改由最高连对/最高分承担。

**Status:** 取代 ADR-0002/0003 中信物与挑战成就的设定；信物概念废除。
