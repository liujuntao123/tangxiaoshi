# 墨潮远征（关卡制）：试玩与验收清单

> 当前版本以关卡制远征为主线（ADR-0018）。旧版三节点墨路/诗签/诗火只保留在历史 ADR，不作为试玩目标。

这份清单判断“像不像一款好玩的游戏”，不是只检查页面能否渲染。360x800、430x932 至少各验一次；桌面宽屏检查舞台居中。

## A. 第一印象

- [ ] 首页第一眼能看出「继续闯关」是唯一主目标。
- [ ] 新用户按钮直达第 1 关；有进度时按钮直达最早未通关关卡。
- [ ] 首页显示已通关 x/50、关卡星星和环游总分，附 50 段进度条。
- [ ] 首页次级入口清楚区分诗集资料库、诗库、无尽模式和诗册。
- [ ] 首屏没有教程墙或大段说明。

## B. 关卡列表

- [ ] `/levels` 显示 50 张关卡卡：关号、星级或状态（可挑战/未解锁）。
- [ ] 顶部汇总已通关数与星星总数。
- [ ] 未解锁关卡置灰不可点；过关第 k 关后第 k+1 关确实解锁。
- [ ] 列表底部用一句话讲清「题目账号专属，重打同关同题」。

## C. 关卡答题

- [ ] 开场说明讲清：10 道题、答对 6 题过关、星级口径、本关可用道具。
- [ ] HUD 显示题号 k/10、答对/答错计数、连击和十格对错进度点。
- [ ] 每道题显示出处（「《诗名》·作者」）。
- [ ] 选项点击后立即锁定，连点不会重复结算。
- [ ] 答对显示完整诗联、得分与连击；双倍生效时标注「双倍」。
- [ ] 答错显示正确答案、出处和相邻诗句；不淘汰、不扣任何资源。
- [ ] 结果不会自动消失，必须点击「下一题 / 看结果」继续（主动确认，不自动跳题）。

## D. 道具

- [ ] 持有道具时答题界面显示道具按钮及数量；数量为 0 时不显示。
- [ ] 去伪：点击后本题隐藏两个错误选项，每题只能用一次，库存即时扣减。
- [ ] 双倍：点击后进入「已备」状态，下一次答对得分翻倍并消耗。
- [ ] 补答：答错后的报告里出现「用补答 · 换一题」；点击后本题不计、新题补位、答错计数回退。
- [ ] 每关最多换 3 题（备用题用完后补答按钮消失）。
- [ ] 道具使用后刷新页面，库存扣减保持（不回滚）。

## E. 结算与奖励

- [ ] 过关结算显示星星、本关得分、答对/答错与最高连击。
- [ ] 首次拿到新星时显示「新星奖励」和获得的道具名；重复同星级通关不重复发奖。
- [ ] 过关后「下一关」直达第 k+1 关；「回关卡列表」返回列表。
- [ ] 未过关显示差几题，可「再试一次」（同一组题）或返回。
- [ ] 过关分数累计进首页「环游总分」。

## F. 题序与防透题

- [ ] 同一账号重打同一关，10 道题完全相同。
- [ ] 不同账号进同一关，题目与顺序不同。
- [ ] 连打多关，关卡之间没有重复题目。

## G. 诗卡与旧入口

- [ ] `/library` 能浏览文集 → 章节 → 作者 → 诗卡；诗卡进入 5 题修页答题（机会灯笼、诗印，写存档）。
- [ ] `/practice` 筛选后进入 `/practice/$poemId`，可先看答案，不写存档。
- [ ] `/endless` 无尽模式照常；`/achievements` 诗册照常。
- [ ] `/endless` 排行榜：开场/结算都能打开；连对/得分双榜可切换，自己的行有「你」印，脚注名次与存档纪录一致；无纪录时显示鼓励文案；返回回到打开前的界面。
- [ ] 旧 `/tour` 深链返回 404/未找到页即可，不做兼容重定向。

## H. 响应式与可访问性

- [ ] 360x800：题干、进度点、选项、反馈按钮均可见。
- [ ] 430x932：报告层不遮挡题干或按钮。
- [ ] 桌面宽屏：舞台保持竖屏比例并居中。
- [ ] 所有可点击元素有清晰文字或 `aria-label`。
- [ ] 禁用按钮状态清楚，键盘焦点不会消失。
- [ ] `prefers-reduced-motion` 下仍能完成全部流程。

## 试玩访谈

打完一关后问：

1. 这一关要做什么才算过关？
2. 答错以后会发生什么？
3. 你的道具是干什么用的？
4. 下一关想不想换个打法（比如攒双倍再冲三星）？

合格答案应接近：答对 6 题过关；答错不淘汰但拿不到高星；能说出至少一个道具用途；愿意为星星重打。若玩家只能说“我在点选项”，优先修正规则表达，不要继续增加装饰。
