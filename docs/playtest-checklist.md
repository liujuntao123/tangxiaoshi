# 唐小诗历险记：试玩与验收清单

> **适配说明（ADR-0015）**：本文成稿于旧「朝代→诗人→关卡」体系。该体系已被卡片式环游重构（ADR-0011..0014）取代：地图/关卡/钥匙/妖怪战斗不复存在，主线为 文集→章节→作者→诗卡。文中的设计意图与数值口径仍然有效，落地方式为——关卡→诗卡、血量→机会灯笼、妖怪→出题作者、地图节点诗印→作者页诗卡诗印；诗签/连击/诗气/收句/结算评级均已在诗卡答题与无尽模式实现。

## 说明

这份清单用于判断“像不像一个好玩的游戏”，不只检查页面能否渲染。每项都应在 360x800 和 430x932 至少各验证一次；桌面宽屏验证舞台居中和不变形。

## A. 第一印象

- [ ] 首页第一眼能看出主目标是“继续历险”，而不是四个同等入口。
- [ ] 新存档可以一键进入第一关。
- [ ] 已有进度能一键回到最早未通关关卡。
- [ ] 首页显示真实的救出诗人、诗印、总分或无尽纪录。
- [ ] 首屏没有大段说明文字或需要先读规则才能开始的教程墙。

## B. 关卡开始

- [ ] 开场对白短而清楚：玩家知道要救谁、前方有什么阻碍。
- [ ] 对白结束后进入诗签选择，不会直接跳过准备阶段。
- [ ] 三枚诗签名称和效果一眼能懂，三者有不同策略价值。
- [ ] 选中诗签后有明显选中态，点开始只会启动一次。
- [ ] 返回再进入同一关，能重新选择诗签。

## C. 战斗手感

- [ ] 战斗 HUD 同时显示玩家血量、妖怪诗魄、题目进度、连击、诗气和当前诗签。
- [ ] 选项足够大，点击后立刻锁定，不会因连点重复扣血。
- [ ] 答对时能明确感到“我攻击了妖怪”：角色、受伤、音效、数字反馈至少出现两种。
- [ ] 答错时能明确感到“我受伤了”：角色、扣血、音效、文字反馈至少出现两种。
- [ ] 连续答对会带来比普通答对更强的可见反馈。
- [ ] 连携触发条件可观察，触发后奖励明显但不破坏平衡。
- [ ] 明心只隐藏错误项，不改变正确答案。
- [ ] 护卷只保护第一次错误，不会让玩家误以为连击保留。
- [ ] 回响只在规定的第一次答对后给下一题奖励，使用完有状态变化。

## D. 学习反馈

- [ ] 答对后能看到“答对”和伤害/连击结果。
- [ ] 答错后正确选项明确高亮，错误选项明确标错。
- [ ] 答错后能看到正确诗句的相邻上下文。
- [ ] 答题结果不会自动消失；玩家必须点击“收句/继续”。
- [ ] 反馈不写成长篇解析，不让玩家在战斗中迷失。
- [ ] 练习模式可以查看答案且不扣血，并显示题目进度。

## E. 胜负与重玩

- [ ] 血量归零进入失败页，能重试，也能回地图。
- [ ] 妖怪诗魄归零先进入结尾对白，再进入结果页。
- [ ] 结果页展示诗印、分数、最高连击、剩余血量。
- [ ] 新纪录有明确提示，未破纪录时不误报。
- [ ] 再战不会重复发钥匙，不会清掉已解锁内容。
- [ ] 重战可以提高诗印或分数，且历史最佳只升不降。
- [ ] 无尽模式答错后先展示本题结果，再进入本局结束页。

## F. 进度与导航

- [ ] 地图能区分锁定、当前可挑战、已通关和最佳诗印。
- [ ] 当前可挑战节点有轻微但不刺眼的提示。
- [ ] 章节页显示钥匙和诗印进度。
- [ ] 成就页显示诗人卡、朝代卡、挑战成就及全局统计。
- [ ] 刷新页面、切换路由、重新登录后进度不丢失。
- [ ] 旧存档没有新字段时不会报错或显示 NaN。

## G. 响应式和可访问性

- [ ] 360x800：题干、角色、选项、反馈按钮都可见，无相互遮挡。
- [ ] 430x932：战斗区不会出现大面积空洞或按钮贴边溢出。
- [ ] 桌面宽屏：舞台保持竖屏比例并居中。
- [ ] 所有可点击元素有清晰文字或 aria-label。
- [ ] 禁用按钮能被看出不可用，键盘焦点不会消失。
- [ ] `prefers-reduced-motion` 下仍能完成所有流程，动画不是必要信息来源。

## H. 工程验收

- [ ] `npm run typecheck` 通过。
- [ ] `npm test` 通过。
- [ ] `npm run lint` 通过，或所有既有例外已记录。
- [ ] `npm run build` 通过，migration 未产生重复或顺序问题。
- [ ] 无关 auth、登录、路由行为没有被改动。
- [ ] 新增状态和规则有纯函数测试，不依赖随机时间或浏览器 DOM。

## 试玩结论

试玩者完成新手第一关后，询问三个问题：

1. 你刚才的目标是什么？
2. 你为什么想再打一遍？
3. 你答错后知道正确答案了吗？

合格答案应分别接近：

- “救出诗人/打败这个妖怪。”
- “想拿更高诗印/分数/连击，或想试另一枚诗签。”
- “知道，正确的诗句在这里。”

如果玩家只能说“我在点选项”，说明战斗幻想仍未成立，应优先修正反馈和奖励，而不是继续增加装饰。
