# 墨潮远征：试玩与验收清单

> 当前版本以墨潮远征为主线。旧版“关卡/地图/妖怪/钥匙”只保留在历史 ADR，不作为试玩目标。

这份清单判断“像不像一款好玩的游戏”，不是只检查页面能否渲染。360x800、430x932 至少各验一次；桌面宽屏检查舞台居中。

## A. 第一印象

- [ ] 首页第一眼能看出“继续远征”是唯一主目标。
- [ ] 新用户看到“点亮第一盏诗火”，已有远征看到“继续远征”。
- [ ] 首页显示三页远征进度、诗火、诗印和总分。
- [ ] 首页次级入口清楚区分诗集资料库、诗库、墨潮试炼和诗册。
- [ ] 首屏没有教程墙或大段说明。

## B. 墨路选择

- [ ] `/tour` 显示当前节点 `1/3`、诗火和三条路线。
- [ ] 每条路线显示真实诗名、作者、文集、风险标签和收益。
- [ ] 青灯小径、风雨险滩、无名残卷具有实际不同效果。
- [ ] 当前路线选择后能进入对应真实诗卡；刷新不会悄悄换卡。
- [ ] `/library` 能浏览文集 → 章节 → 作者 → 诗卡；首页底部「文集」直达。
- [ ] 旧深链 `/tour/$collectionId/…` 重定向到 `/library` 对应层级。
- [ ] 当前节点已领诗卡时，`/tour` 页首有「续修本页」快捷且能回到原诗卡。

## C. 诗页修复

- [ ] 进入诗卡先选明心、护卷或回响，选择态和效果清楚。
- [ ] HUD 显示节点、路线、诗火、题号、连击、诗气和当前诗签。
- [ ] 选项点击后立即锁定，连点不会重复结算。
- [ ] 答对显示“诗页补回一行”、得分、连击和路线/奖励加成。
- [ ] 答错显示“墨潮抹去一盏诗火”、正确项和相邻诗句。
- [ ] 结果不会自动消失，必须点击“收句”继续。
- [ ] 明心、护卷、回响均只能按当前规则使用一次。

## D. 节点与结局

- [ ] 节点通关后出现修页奖励；续灯、磨墨、听句至少有两种可选。
- [ ] 选择奖励返回路线页后，下一节点能观察到奖励实际生效。
- [ ] 青灯小径回复诗火；风雨险滩正确答案加分；无名残卷提供三选。
- [ ] 失败显示“墨潮未退”，可以重战当前页或另选墨路。
- [ ] 三节点零错误显示“诗声复明”；有错误但完成显示“带伤归卷”。
- [ ] 结算期间不会因节点索引推进而丢失奖励和结局面板。

## E. 永久进度与边界

- [ ] 远征刷新后仍能恢复当前节点和路线。
- [ ] 诗卡通关、诗印、最佳分和总分写入 PlayerSave。
- [ ] 旧存档缺少远征状态时不报错；远征状态不是账号云存档。
- [ ] 诗库、墨潮试炼、诗册和资料库旧路由仍可用。

## F. 响应式与可访问性

- [ ] 360x800：题干、角色、选项、反馈按钮均可见。
- [ ] 430x932：反馈层不遮挡题干、角色或收句按钮。
- [ ] 桌面宽屏：舞台保持竖屏比例并居中。
- [ ] 所有可点击元素有清晰文字或 `aria-label`。
- [ ] 禁用按钮状态清楚，键盘焦点不会消失。
- [ ] `prefers-reduced-motion` 下仍能完成全部流程。

## G. 工程验收

- [ ] `npm run typecheck` 通过。
- [ ] `npm run lint` 通过，或明确记录已有例外。
- [ ] `npm test` 通过，或区分项目测试与环境夹具失败。
- [ ] `npm run build` 通过。
- [ ] 内容改动额外运行三条内容编译/验证命令。
- [ ] 本次修改已同步 `README.md`、`CONTEXT.md`、相关 docs/ADR 和 `changelog.md`。

## 试玩访谈

完成一次远征节点后问：

1. 你现在要修复什么？
2. 为什么选这条墨路？
3. 答错后知道正确答案了吗？
4. 下一次会换路线、诗签还是修页奖励？

合格答案应接近：修复失声诗页；因为路线有不同风险/收益；知道正确诗句；愿意尝试不同策略。若玩家只能说“我在点选项”，优先修正决策和反馈，不要继续增加装饰。
