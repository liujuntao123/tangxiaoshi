# 唐小诗环游记：游戏设计总案

> 版本：关卡制墨潮远征 3.0（2026-09-06）
> 用途：定义当前主线体验、边界和验收标准。旧版三节点/墨路设计见 ADR-0016（已取代）；当前主线决策见 ADR-0018。

## 1. 产品定位

《唐小诗环游记》是一款给小学高年级和初中生玩的竖屏古诗文闯关游戏。玩家扮演修页人唐小诗，沿 50 个平铺关卡修复被墨潮抹去的诗句：每关 10 道题，答对 6 题过关，过关拿星星和道具。

体验承诺：玩家每次都知道下一步去哪；规则一句话能讲清（10 题、6 题过关、星星换道具）；答错能看懂正确诗句；每关的题目是自己账号专属的，和别人不一样。

## 2. 三个设计支柱

1. **规则直白**：关卡只有序号，没有难度维度；道具名称即用途（去伪/补答/双倍）；不用需要先学一套隐喻的抽象词。
2. **内容随机而不重复**：每关 10 题从全库题池抽取，一诗一题，关卡之间零重复；同一玩家的题目永远固定，不同玩家互不相同，玩家之间无法透题。
3. **反馈形成节奏**：作答 → 对错反馈（完整诗联 + 出处）→ 主动确认（「下一题 / 看结果」）→ 下一题；结算 → 星级 + 道具奖励 → 下一关。

## 3. 当前不做

- 不做动作操控、走位、实时躲避或技能树。
- 不做妖怪、血条、攻击/受击帧、钥匙门控、旧地图解锁。
- 不做装备稀有度、抽卡、体力、付费货币或随机箱。
- 不做排行榜压迫、长篇赏析或强制教程墙。
- 不做难度分层：所有关卡平铺，内容差异由随机抽题自然产生。

## 4. 玩家旅程

### 首次进入

首页是远征台。主按钮「继续闯关」直达下一关；新存档从第 1 关开始。底部次级导航：文集（资料库）、诗库、墨潮试炼、诗册。

### 一关

```text
远征台 / 关卡列表
  -> 进入第 N 关（开场说明：10 道题 · 答对 6 题过关 · 持有道具）
  -> 逐题作答（显示出处；答错不淘汰，给正确诗句和相邻句）
       -> 需要时用道具：去伪（隐两个错项）/ 双倍（下次答对翻倍）/ 补答（错题换新题）
  -> 逐题确认推进（下一题/看结果），10 题答完结算
       -> 过关：星级 + 新星道具奖励 + 得分入总分，解锁下一关
       -> 未过关：重打还是同一组题，把没记牢的诗句补上
```

### 长期体验

永久进度来自关卡星星、道具库存、环游总分、诗卡通关与诗印（资料库路径）、作者/文集/朝代成就和墨潮试炼纪录。关卡星星与道具是账号级存档，跨设备一致。

## 5. 关卡与出题算法

| 项目 | 规则 |
| --- | --- |
| 关卡数 | `LEVEL_COUNT = 50`，平铺，顺序解锁 |
| 每关题量 | `QUESTIONS_PER_LEVEL = 10` 道正式题 + 3 道备用题 |
| 题库池 | `bank.json`：2147 首诗 × 每诗 5 题 = 10735 题 |
| 取题 | 一诗一题；第 k 关占用玩家专属诗序的第 `[(k-1)*13, k*13)` 首 |
| 种子 | `levelSeed(userId)`：FNV-1a 折叠 userId → mulberry32 确定性洗牌全库诗 |
| 防透题 | 同一玩家题目固定，不同玩家题目与顺序互不相同 |
| 防重复 | 关卡内 10 首诗互不相同；关卡间诗段互不重叠（50 关共用 650 首 < 2147 首） |
| 过关线 | `LEVEL_PASS = 6`：答对 6 题过关 |
| 星级 | 零答错三星；答错 ≤2 两星；其余过关一星；失败零星；每关只记历史最佳 |

算法实现在 `src/lib/game/levels.ts`（纯函数，`levels.test.ts` 直测确定性、防重复与奖励发放）。

## 6. 道具

| 道具 | 使用时机 | 效果 |
| --- | --- | --- |
| 去伪 | 作答前点击 | 隐藏本题两个错误选项（每题一次） |
| 补答 | 答错后的报告里点击 | 本题撤下不计，换一道备用题补位（每关最多 3 次） |
| 双倍 | 作答前点击 | 接下来第一次答对得分翻倍（答错不返还） |

- 道具是**持久库存**（`PlayerSave.items`），跨关卡、跨会话；使用即扣减并即时落存档。
- 奖励口径一句话：**每拿到一颗新的星星，奖励 1 个随机道具**。种类由 玩家+关卡+星档 的种子决定，可复盘、可复现。
- 关卡开场说明会列出本关可用道具；答题时道具按钮常驻（持有才显示）。

## 7. 得分与反馈

- 单题得分沿用连击口径：基础 100 分，连击每层 +25（封顶 +100），连携 +100；双倍道具把该题得分翻倍。
- 过关分数累加进 `totalScore`；重复通关照常累计（与诗卡口径一致）。
- 答对反馈「答对了」+ 完整诗联 + 得分明细；答错反馈正确答案 + 出处（「《诗名》·作者」）+ 最多两行相邻诗句。
- 所有反馈必须等待玩家点击「下一题/看结果」，不得自动切题。
- 关内 HUD：第 k/10 题、答对/答错计数、连击、十格对错进度点。

## 8. 状态与存档

答题状态机（关卡）：

```text
intro -> battle -> resolving -> battle ... -> result
```

关卡没有独立的「进行时」状态：题目由 userId 即时确定性生成，进度只落在 `PlayerSave`，刷新、换设备都不丢。

永久成绩由 `PlayerSave` 保存（migration `0005_level_progress.sql`）：

```ts
clearedPoems: string[];              // 资料库诗卡通关（/play 路径）
achievements: string[];
endlessBestStreak: number;
endlessBestScore: number;
metAuthors: string[];
poemRecords: Record<string, { bestStars: 0 | 1 | 2 | 3; bestScore: number; bestCombo: number; attempts: number }>;
totalScore: number;
levelStars: Record<string, 0 | 1 | 2 | 3>;  // 关卡历史最佳星级，key 为关号
items: { reveal: number; redo: number; double: number };  // 道具库存
```

## 9. 页面职责

- 首页 `/`：远征台。主按钮「继续闯关」直达下一关（`/levels/$levelId`）；50 段进度条 + 已通关/星星/总分；全部通关后变「挑战满星」。
- `/levels`：关卡列表。50 张卡：关号、星级、可挑战/未解锁；顶部汇总已通关数与星星数。
- `/levels/$levelId`：关卡答题场。开场说明 → 答题 → 结算（星级/奖励/得分），过关可直达下一关。
- `/library`：诗集资料库，文集 → 章节 → 作者 → 诗卡；诗卡进入 `/play/$poemId`（5 题、机会灯笼、诗印，写存档）。
- `/practice` + `/practice/$poemId`：诗库筛选与自由练习（先看答案，不写存档）。
- `/endless`：墨潮试炼，一题错即止。
- `/achievements`：诗册和三类收集成就。

## 10. 视觉与响应式标准

保留古风 Q 版绘本、纸面板、竹简/木牍选项和现有立绘。用纸米色、松青、朱砂和少量墨色表达状态；重要状态同时使用文字、形状和动画。360x800、430x932 和桌面宽屏均需保证题干、选项和按钮不重叠；尊重 `prefers-reduced-motion`。

UI 卡片语言（2026-09 UI 走查后固化，令牌与组件见 `src/styles.css` 与 `stage.tsx`）：

- **对比度红线**：纸面板（浅底）上一律深墨文字/描边；场景图上的说明文字用 `caption-pill`（深墨胶囊）或 `paper-glow`，禁止裸 `text-paper/xx` 压浅背景。
- **列表行卡**：头像/图腾在 `medal`（玉环圆框）或 `art-slot`（图槽）里承托，中间是标题 + 元信息，右端 `RowChevron` 进入箭头；整行禁止出现大面积空白。
- **关卡卡**：关号 + 星级（★）/状态（可挑战/未解锁），锁定卡置灰。
- **入场节奏**：列表卡用 `rise-in` 逐张错峰浮现（`animationDelay` 约 40–70ms/张）。
- `ArtPanel` 的 `className`/`style` 只描述内容层排版，不落在 border-image 外壳上。

## 11. 内容原则

题目不在运行时生成，唯一内容源见 `docs/content.md`。关卡只从已编译题池按确定性算法抽题。对白短、口语化；作者是守卷人而非敌人；答错展示诗句上下文，不写大段解析。

## 12. 验收

- 新用户首屏 3 秒内知道「继续闯关」是主目标，且按钮直达第 1 关。
- 关卡列表能分清哪些关可打、哪些未解锁；过关后下一关确实解锁。
- 一关内能感受到：题目出处、答错不淘汰、主动确认推进、道具可用。
- 过关结算能看到星级与道具奖励；重复通关同星级不重复发奖。
- 不同账号同一关的题目不同；同一账号重打同一关题目相同。
- 刷新、换设备都不丢关卡进度与道具；旧 `PlayerSave`（缺新字段）打开不报错。
- 运行 `npm run typecheck`、`npm run lint`、`npm test`、`npm run build`。
