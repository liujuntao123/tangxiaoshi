# 唐小诗环游记：游戏设计总案

> 版本：墨潮远征 2.0（2026-09-06）
> 用途：定义当前主线体验、边界和验收标准。旧版关卡/妖怪设计已归档，历史背景见 ADR-0001–0015；当前主线决策见 ADR-0016。

## 1. 产品定位

《唐小诗环游记》是一款给小学高年级和初中生玩的竖屏古诗文短局冒险游戏。玩家扮演修页人唐小诗，在“墨潮”吞噬诗句前沿三条墨路修复三页失声诗文。

体验承诺：玩家每次都知道下一步去哪；答题有明确的取舍和反馈；答错能看懂正确诗句；完成节点后有可感知的奖励；一局结束能说清为什么得到这个结果，也知道为什么值得再玩。

## 2. 三个设计支柱

1. **路线有差异**：每个节点在青灯小径、风雨险滩、无名残卷中三选一。路线绑定真实诗卡，并提供不同风险/收益。
2. **状态会改变旅程**：诗火、连击、诗签和修页奖励只服务当前远征，但会改变下一节点的难度、分数或信息量。
3. **反馈形成节奏**：作答 → 诗页/墨潮反馈 → 阅读正确答案 → 主动“收句” → 下一题；节点结算 → 选奖励 → 下一节点。

## 3. 当前不做

- 不做动作操控、走位、实时躲避或技能树。
- 不做妖怪、血条、攻击/受击帧、钥匙门控、旧地图解锁。
- 不做装备稀有度、抽卡、体力、付费货币或随机箱。
- 不做排行榜压迫、长篇赏析或强制教程墙。
- 不把远征进行时状态冒充账号级云存档。

## 4. 玩家旅程

### 首次进入

首页显示墨潮远征台。主按钮是“点亮第一盏诗火”，进入 `/tour`，玩家看到三条真实墨路并选择第一张诗卡。

### 一次远征

```text
远征台
  -> `/tour` 三条墨路中选一条
  -> 选一枚诗签
  -> 5 题诗页修复
       -> 正确：诗页补回、连击/诗气/分数增加
       -> 错误：墨潮逼近、诗火减少、连击清零、展示上下文
       -> 点击“收句”才继续
  -> 节点结算
       -> 中盘：选择修页奖励
       -> 第三页：诗声复明 / 带伤归卷
       -> 失败：墨潮未退，可重走此页或另选墨路
```

一次远征最多三个节点。每个节点绑定一张真实诗卡，仍使用题库固定的 5 题和 60% 及格规则；远征诗火决定当前节点的机会灯笼数，范围 1–4。

### 长期体验

永久进度来自诗卡通关、诗印、最佳分、总分、作者/文集/朝代成就和墨潮试炼纪录。远征路线加成进入该次诗卡的最佳分与总分；远征奖励不会永久成为装备。

## 5. 墨路与短期状态

| 墨路 | 候选池 | 实际效果 |
| --- | --- | --- |
| 青灯小径 | 优先从未通关诗卡抽取 | 节点成功后额外回复 1 盏诗火 |
| 风雨险滩 | 优先从已通关诗卡抽取 | 每题正确额外 +50 分 |
| 无名残卷 | 从全部题库抽取 | 节点成功后可从续灯/磨墨/听句三选一 |

候选通过 `offerSeed` 确定性生成，刷新和回看不会在同一节点悄悄换卡。

### 诗签

| 诗签 | 效果 |
| --- | --- |
| 明心 | 本页使用一次，隐藏两个错误选项 |
| 护卷 | 本页第一次答错不损失诗火，但仍断连 |
| 回响 | 第一次答对后，下一次符合条件的正确答题获得额外分数与诗气 |

### 修页奖励

- 续灯：领取时立即增加 1 盏诗火，封顶 4。
- 磨墨：下一节点第一题答对额外 +100 分。
- 听句：下一节点第一题前显示该诗第一行。

普通路线提供续灯/磨墨二选一；无名残卷额外提供听句。

## 6. 结局与反馈

- 零错误节点评价为“清声”，有错误但通关为“留痕”。
- 三页全部通关且累计零错误：`诗声复明`。
- 三页全部通关但有错误：`带伤归卷`。
- 当前节点失败时显示 `墨潮未退`；失败状态不永久锁死，重走会重新点亮诗火。
- 答对反馈“诗页补回一行”，显示连击、诗气、得分和路线/奖励加成。
- 答错反馈“墨潮抹去一盏诗火”，显示正确选项和最多两行相邻诗句。
- 所有反馈必须等待玩家点击“收句”，不得用短定时器自动切题。

## 7. 状态与存档

答题状态机：

```text
loadout -> battle -> resolving -> battle ... -> result
```

远征状态由 `src/lib/game/expedition.ts` 管理，存浏览器 `localStorage` key `tangxiaoshi.expedition.v1`；normalize、读写失败降级和状态转移集中在该模块。它可跨刷新恢复，但不跨设备、不跨浏览器，也不按账号隔离。

永久成绩仍由 `PlayerSave` 保存：

```ts
clearedPoems: string[];
achievements: string[];
endlessBestStreak: number;
endlessBestScore: number;
metAuthors: string[];
poemRecords: Record<string, { bestStars: 0 | 1 | 2 | 3; bestScore: number; bestCombo: number; attempts: number }>;
totalScore: number;
```

## 8. 页面职责

- 首页：远征台、唯一主目标、三页进度、诗火/诗印/总分。主按钮语义：当前节点已择墨路时「继续远征」直达该页答题（续修本页，`/play/$poemId?route=&node=`）；未择墨路时进 `/tour` 择路。
- `/tour`：只承载当前节点三条墨路（ADR-0017 起资料库迁出，不再有 `?view=library` 视图切换）。当前节点已领诗卡时页首提供「续修本页」快捷，直达该页答题。
- `/library`：诗集资料库，文集 → 章节 → 作者 → 诗卡；底部导航「文集」直达，与远征分家。
- `/play/$poemId`：诗卡答题、诗签、诗火、修页奖励和结算。
- `/practice`：诗库筛选和无压力练习。
- `/endless`：墨潮试炼，一题错即止。
- `/achievements`：诗册和三类收集成就。

## 9. 视觉与响应式标准

保留古风 Q 版绘本、纸面板、竹简/木牍选项和现有立绘。用纸米色、松青、朱砂和少量墨色表达状态；重要状态同时使用文字、形状和动画。360x800、430x932 和桌面宽屏均需保证题干、角色、选项和收句按钮不重叠；尊重 `prefers-reduced-motion`。

UI 卡片语言（2026-09 UI 走查后固化，令牌与组件见 `src/styles.css` 与 `stage.tsx`）：

- **对比度红线**：纸面板（浅底）上一律深墨文字/描边；场景图上的说明文字用 `caption-pill`（深墨胶囊）或 `paper-glow`，禁止裸 `text-paper/xx` 压浅背景。
- **列表行卡**：头像/图腾在 `medal`（玉环圆框）或 `art-slot`（图槽）里承托，中间是标题 + 元信息 + `meter` 进度条，右端 `RowChevron` 进入箭头；整行禁止出现大面积空白。
- **墨路任务卡**：三条路线各有类别色（灯金 `lamp`、雨峡青 `storm`、暮山紫 `dusk`），以色脊 + 单字徽章 + 同色 tag/收益 pill 表达，右端是「启程」圆形 CTA。
- **旅程节点**：`jdot` 墨座圆点 + 渐隐连接线；完成盖朱印、当前呼吸高亮、失败沉墨。
- **入场节奏**：列表卡用 `rise-in` 逐张错峰浮现（`animationDelay` 约 45–70ms/张）。
- `ArtPanel` 的 `className`/`style` 只描述内容层排版（flex、text-center、错峰延迟），不落在 border-image 外壳上。

## 10. 内容原则

题目不在运行时生成，唯一内容源见 `docs/content.md`。对白短、口语化；作者是守卷人而非敌人；答错展示诗句上下文，不写大段解析。

## 11. 验收

- 新用户首屏 3 秒内知道“继续远征”是主目标。
- `/tour` 每个节点有三条真实路线，路线效果确实不同。
- 诗火、路线加成、修页奖励能在下一节点观察到。
- 答对/答错后不能自动跳题，正确答案和上下文清楚。
- 第三节点或失败结算能说明因果，并提供重玩理由。
- 刷新不丢当前远征；旧 `PlayerSave` 不报错。
- 运行 `npm run typecheck`、`npm run lint`、`npm test`、`npm run build`。
